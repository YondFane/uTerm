# 数据库工作台实施计划

[English](database-workbench-plan.md)

## 目标与边界

围绕找对象、看数据、写 SQL、处理事务建立轻量工作台。复用 React、CodeMirror、Tauri 和内置 JDBC 引擎，Java 与厂商驱动继续可选安装；不引入另一套编辑器、数据库服务端或大型表格框架。保留活动终端、凭据、连接身份、SQL 草稿及事务／退出保护。本计划描述待实施工作，[features.zh-CN.md](features.zh-CN.md) 描述当前产品行为和实际验证。

## 第一批：基础工作台

状态：已实现。Windows 原生工作台及临时 MySQL 验证通过；macOS、PostgreSQL／Oracle 验收及同配置 Release 安装包增量测量待完成。具体覆盖范围与限制见功能说明。

- 将平铺的元数据按钮改为当前连接的对象树，支持筛选已加载对象。按实际类型展示 MySQL 库及 PostgreSQL／Oracle 模式，表与视图分组，系统对象折叠。
- 查询编辑器／结果与表的“数据／结构”视图分开。选择对象不覆盖 SQL 或查询结果；生成 SELECT 需显式操作，并保留草稿保护。
- 精简连接／操作区域。对象浏览区及 SQL／结果分隔线支持键盘和指针调整，各区独立滚动，底部分页始终可见。本次运行内切换连接／工作区保留布局和视图状态。
- 提供有界只读表预览、单元格／行／区域选择、可选表头的键盘复制、列宽调整及已加载值的完整查看。区分 NULL、空字符串、二进制、截断值，结果数据与消息分开。
- 将元数据和表预览读取与可写连接的事务隔离。每个工作台按需复用一个只读浏览连接，保留资源上限及认证／端点检查，随所属连接关闭，分配／连接失败可见。浏览不得提交或回滚 SQL 事务。
- 保留保守的写入确认、事务和草稿保护；明确取消会关闭连接。不自动重放 SQL，不默认执行全表计数。

验收：搜索 student → 打开数据 → 查看结构 → 返回未改变的 SQL／结果 → 执行 SQL → 复制区域。有待提交写事务时重复浏览，确认事务未被结束。Windows 检查正常／窄窗口、指针／键盘调整、固定分页、隐藏工作台状态保留及可见错误，如实记录其他平台／服务端的待验收项。

## 第二批：SQL 效率

计划支持：多个查询标签及明确的会话／事务归属；按方言解析后执行选中／当前语句／全部；SQL 补全／格式化、错误定位和查询历史。支持带注释 SELECT 及只读 CTE，不把所有 WITH 判为只读。历史默认仅在内存中保留，跨重启恢复作为独立显式设置。区分服务端表筛选和任意查询已加载结果的本地筛选。

## 第三批：受控数据维护

计划支持：表格编辑、增删行、SQL 变更预览、过期数据冲突检查、导出及执行计划。可编辑结果必须具备可靠唯一键，否则保持只读。另行评估驱动支持的保留连接取消能力，保留显式事务处理及写入结果未知的提示。

## 体积预算与验证

以下为压缩安装包增量估算，并非实际测量结果：

| 批次   | 增量       |
| ------ | ---------- |
| 第一批 | 0.1–0.4 MB |
| 第二批 | 0.2–0.8 MB |
| 第三批 | 0.2–0.8 MB |
| 合计   | 0.5–2 MB   |

前后对比使用相同系统、架构、Release 参数及打包格式。累计增加 2 MB 是依赖审核检查线，不是保证的上限。前端 gzip 大小只作为诊断，不能代替安装包测量。额外连接主要影响运行内存；历史／导出文件属于用户数据，不计入安装资源。验证锁定依赖、修改文件格式、国际化／文档、前端测试／构建及相关后端检查。原生 QA 使用隔离应用标识，不替换或重启正在使用的安装版。
