# uTerm 功能说明

[English](features.md) · [环境与命令](../README.md)

## 产品范围

uTerm 是 Windows 和 macOS 桌面终端。本地终端和 Agent 进程在本机运行，SSH 远程 Shell 在服务器运行。界面支持简体中文和英文。

## 项目官网

`site/` 中独立的 GitHub Pages 官网介绍终端与 Agent、项目与 Git、SSH/SFTP 和 Redis／数据库。四个标签明确标注为使用示例内容的界面示意，不连接真实桌面会话或服务器。六种界面配色仅改变预览。简体中文／英文切换更新正文、无障碍标签、页面元数据及文档链接；浏览器禁止存储时仍可切换。标签支持方向键、Home 和 End 导航。

Windows x64、macOS Apple Silicon 和 macOS Intel 下载入口初始指向 GitHub 稳定版发布页。公开的最新发布 API 成功时，解析为本仓库该版本对应的安装包；缺少资源、请求限流或网络失败时保留发布页入口。安装标签提供已有的 npm／macOS／PowerShell 命令，复制成功会提示，剪贴板不可用时选中命令并显示手动复制说明。数据库使用仍需 Java 17+ 和所选驱动，macOS 首次启动可能需要在“隐私与安全”中批准。

使用 `pnpm site:dev` 在回环地址的 `/uTerm/` 下预览，`pnpm site:check` 运行专项交互检查。Pages 工作流只从 `release` 上传 `site/`；仓库 Pages 需选择 GitHub Actions，且 `github-pages` 环境需允许该分支。发布需要已审查的官网改动进入 `release`。本地浏览器检查不代表线上 Pages 部署或桌面运行验收。

官网 Windows 验证：七项专项检查和完整前端／构建工具套件通过（225 项通过，十项可选／平台检查跳过）。修改文件格式、脚本语法、文档检查及 TypeScript／生产构建通过。浏览器检查覆盖中英文、1280×720、768×1024 和 390×844 无页面溢出的布局、预览标签、深浅配色、键盘焦点及实际安装命令复制。已核对公开发布元数据和安装包名称；浏览器 API 请求无法解析时保留发布页入口，直接安装包解析由夹具检查覆盖。预览只提供官网资源，拒绝读取仓库文件路径。全仓格式检查报告 92 个文件的既有问题；套件仍有 Vite WebSocket 端口／React act 警告，应用构建保留大代码包警告。Pages 部署已成功完成，公开首页返回 HTTP 200。

## 安装

仓库侧栏的 Latest 入口指向稳定安装包版本。发布流水线在公开下载验证和稳定更新清单发布成功后，才将版本标记为 Latest。预发布更新通道不会标记为 Latest。

Latest 验证：6 项发布工具测试、工作流格式、步骤顺序及 Shell 语法检查，以及文档检查通过。线上 Latest 接口指向已发布稳定版，发布名称、说明和 11 项上传资源记录保持完整。

[README](../README.md#一行命令安装) 提供终端和 PowerShell 一行安装命令，对应 `scripts/install/install.sh` 和 `scripts/install/install.ps1`。脚本读取对应平台的稳定更新清单，并通过 HTTPS 从本仓库下载匹配版本的安装包。macOS 自动选择 Apple Silicon 或 Intel（包括 Rosetta 检测），只读挂载 DMG，安装到 `~/Applications/uTerm.app`，不使用 sudo，也不启动应用。保留已有用户级／系统级安装，请使用应用内更新。Windows x64 打开安装向导，并报告非成功退出码。安装包最多尝试下载三次。稳定更新清单提供安装包大小和 SHA-256 时，中断下载保留并续传，完整缓存重新校验后复用；旧清单仍可使用，但每次重新下载，不持久复用安装包。挂载和暂存临时文件会清理；已校验的安装包缓存最多保留四个文件，后续使用时清理超过七天的非当前文件。Windows 使用缓存锁；macOS 使用锁目录，强制终止后可能需要手动移除残留锁目录。失败时输出官方手动下载页。需要访问 GitHub，无需开发工具链。应用未经 Apple 公证，首次启动可能需要在“隐私与安全”中批准。远程命令需要脚本已发布到 `release`。

`scripts/install` 中的独立 npm 包通过 npx、pnpm dlx 或全局安装提供 `uterm-install` 命令，需要 Node.js 22.13 或以上。命令以独立参数调用包内平台脚本，不使用 Shell 插值，并保留安装器退出码。帮助及无效参数不会启动安装。包不使用安装生命周期钩子；安装／移除 npm 包只管理命令，不安装／卸载桌面应用。包已以 `@yondfane/uterm-install` 名称发布到 npm。

验证：macOS 上的 150 项前端／构建工具测试、39 项后端测试、本地会话服务测试、锁定依赖安装、格式、国际化、文档检查和 TypeScript／生产及桌面构建通过。Shell 语法和模拟 macOS 安装测试覆盖原生／Rosetta 架构选择、含空格路径、不支持的平台、无效版本号、下载失败及已有安装保护。npm 入口测试覆盖平台分派、独立参数、帮助、无效输入及失败退出码。本地打包的 tarball 在 macOS 上通过 npm exec 和 pnpm dlx 帮助冒烟检查；npm pack 确认包含两个平台脚本。已发布的 npm 0.1.0 包也通过 npx 和 pnpm dlx 帮助检查。测试不会下载或安装应用。真实 macOS 安装及 Windows PowerShell／运行验收仍未验证。

## 工作区与会话

项目和 Worktree 行在悬停或聚焦时保留文件夹图标，不显示独立下拉按钮。左键点击图标、名称或行标签剩余空白处可展开／折叠子项；聚焦该行后按 Enter／空格执行相同操作。原有项目／会话选择及编辑器切换保护继续生效。右键菜单、拖动和行内快捷操作按钮不会触发折叠。活动树折叠状态保留在本次运行内存中，非活动项目／Worktree 仍沿用已保存的折叠设置；折叠后仍显示使用状态圆环。

侧栏会话的“关闭会话”按钮与 SSH／Redis／数据库的移除按钮，仅在鼠标悬浮到所在行或行内有键盘焦点时显示，仅选中该行不会使按钮常显。隐藏时不响应鼠标，保留原有占位，避免名称跳动；键盘导航仍能显示并使用这些按钮。

## SSH 与远程文件

侧栏中的 SSH 连接属于当前工作区。添加连接时可填写主机地址、端口（默认 22）、用户名、远端系统（Linux/macOS 或 Windows）和可选文件根目录。用户名留空使用 OpenSSH 配置或本机账户，根目录留空使用服务端登录目录。Host 别名模式保留已有配置，读取 `~/.ssh/config` 及 Include 文件，不改写原文件；别名模式中端口和用户名留空时继承 OpenSSH 配置。认证支持 OpenSSH 自动选择、私钥文件/ssh-agent，以及在连接窗口输入密码。需要系统已安装 OpenSSH；Windows 可安装 OpenSSH 客户端可选功能。这些连接选项不捆绑 SSH 可执行文件、JVM 或新增运行时依赖。

密码默认仅在本次应用运行期间有效；勾选“记住密码”后存入 macOS Keychain 或 Windows Credential Manager，工作区和会话数据只保存不透明引用。编辑时密码留空可保留现有密码，也可切换临时内存与系统凭据库保存方式。密码绑定连接及解析后的目标，目标变化后需重新输入。保存失败只回滚新建凭据，保留原配置。凭据库中的密码不会返回前端，也不会进入进程参数、环境变量、工作区文件或日志。短期有效且需认证的回环辅助程序通过 OpenSSH askpass 提供一次密码，并复用应用自身可执行文件。密码模式支持普通密码认证，未知主机指纹通过原生对话框确认；拒绝 ProxyJump/ProxyCommand、验证码及修改密码提示。自动/密钥模式保留 OpenSSH 跳板机行为；有口令的私钥用于文件或隧道前需加入 ssh-agent。

每个连接支持多个终端会话，以及同一连接内的置顶、排序和分屏。SSH 使用现有本地 PTY 服务，保留终端输入、尺寸同步和输出回放。自动/密钥模式在终端确认主机指纹和处理交互认证；密码模式使用连接中配置的密码并通过原生对话框确认指纹。退出应用时分离界面，本机 SSH 进程继续运行；关闭会话终止该 SSH 进程，远程进程是否继续取决于服务端。重新打开应用会附着已有会话，不会静默启动新的网络登录。“重新启动”创建新会话，并保留旧输出。网络故障后不恢复原远程 Shell；持续运行的服务端任务需要 tmux 等工具。旧后台服务需要先关闭其会话并安全重启，才能启用 SSH。

选择连接可打开 SFTP 文件面板，使用该配置的主机、端口、用户名和认证方式。自动/密钥模式需要可信主机及密钥/ssh-agent 非交互认证；未知主机应先在 SSH 终端确认。密码模式也可通过原生对话框确认新主机。文件根目录独立于 Shell 中的 `cd`；Windows 根目录必须位于本地盘符下，不支持 UNC 共享。暂不提供远程 Git、GitHub、本地目录工具、全目录搜索、目录传输、递归删除和断点续传。

文件树支持隐藏文件、文本编辑、受支持的图片/PDF 预览、新建文件/目录、重命名，以及删除文件或空目录。文本继续遵循 2 MB 上限、UTF-8/BOM 和换行处理，并保留冲突检查、保存/关闭保护及本机恢复草稿。文件身份包含 SSH 连接、解析后的目标与规范根目录，配置变化后草稿不会静默写向另一台服务器。符号链接读取限制在根目录内，拒绝通过链接修改文件。路径按远端规则处理，不展示名称含反斜杠、冒号或控制字符的远程文件。

保存使用同目录临时文件、内容版本检查及服务端的 `posix-rename@openssh.com` 扩展，不以先删除原文件的方式降级覆盖。服务器不支持安全替换时，允许读取、下载和上传新文件，已有文件以只读方式打开。可用时保留普通权限位；uTerm 不保留 Windows ACL。冲突检查采用乐观校验，不能阻止其他服务端程序并发写入。提交后发生网络故障时，结果可能不确定；应保留草稿并重新读取，再决定是否重试。

可从工具栏或目录右键菜单上传文件，从普通文件的右键菜单下载到原生保存对话框选择的位置。传输分块流式处理，显示字节进度、完成、错误与取消状态。上传覆盖默认关闭，需要明确勾选；拒绝目录与链接传输。取消时尝试清理临时文件，断线时可能留下需要手动清理的 `.uterm-*` 临时文件。有传输进行时退出，会先提供等待或取消传输的选择，再经过编辑器保存保护。传输期间不能安装更新。最多同时传输四个任务、缓存十六个远程文件连接；“重新连接”释放该连接此前的文件通道。连接仍有会话、保留的文件标签、进行中的传输，或依赖它的 Redis 工作台已连接、忙碌或有草稿时，禁止编辑和移除。移除前还需移除依赖的 Redis 配置。保存空闲 SSH 配置时同步更新依赖的 Redis 配置；已记住的 Redis 凭据仍绑定原目标。已有会话保留原目标。

验证：macOS 自动化测试覆盖数据升级、连接/会话隔离、分组、目标校验、远程草稿身份、恢复时仅附着已有会话、排除本地工具及限制进度更新频率。真实系统 SFTP 服务测试覆盖中文名称、安全保存、冲突、根目录越界/链接拒绝、文件操作、流式上传下载、取消覆盖及临时文件清理。隔离原生应用（`sh.uterm.desktop.qa.ssh`）连接了回环地址上的 OpenSSH 服务，验证主机指纹确认、远程 Shell 输出、退出重开后的附着与回放、独立关闭分屏、文件编辑、冲突保留、上传/下载字节一致、文件通道重连、传输进度、取消清理及传输退出保护。连接与密码验证另包括：macOS 上 187 项前端及构建工具测试、32 项本地服务测试、56 项常规后端测试和六项 Redis 专项测试通过，覆盖旧选项序列化、版本 6 数据升级、无效字段/明文凭据拒绝、端口/用户/密钥参数分离、凭据目标绑定、保存失败清理、Redis 隧道完整配置，以及需认证的一次性 askpass、消息上限、指纹批准/拒绝和意外提示拒绝。隔离原生 QA（`sh.uterm.desktop.qa.sshauth`）使用真实系统 OpenSSH 和可丢弃的回环密码服务，验证指定端口/用户名、别名继承/HostKeyAlias、密码 SFTP 读取及中文文本保存、终端输出/重连附着、Redis 隧道 PING 和数据读取、重开应用后的 Keychain 保存/读取、凭据移除、临时密码重启失效，以及原生主机指纹窗口的批准/取消。Windows 客户端/服务端、Credential Manager 和 Linux 运行仍未验证；密码模式不支持跳板机及 OTP。

## Redis 连接与工作台

Redis 连接属于工作区。从侧栏添加名称、地址、端口、数据库编号和可选 ACL 用户名/密码。“测试连接”执行认证和 PING 后释放临时连接。恢复配置时不会自动连接。支持 TCP 直连、TLS，以及从现有 SSH 连接中选择的系统 OpenSSH 隧道。隧道模式由 SSH 服务器访问 Redis 地址；`127.0.0.1` 指该服务器。隧道复用所选配置的主机、端口、用户名和自动/密钥/密码认证，并需要 TCP 转发权限；继续兼容只有别名的旧 Redis 配置。密码模式的主机确认和凭据有效期遵循 SSH 配置。TLS 也可用于隧道内部，始终验证 Redis 服务端名称；可选 PEM CA 证书及服务端名称覆盖，CA 留空时使用系统信任。不提供双向 TLS。

工作台在权限允许时显示服务端版本、角色及 PING 延迟，部分信息不可用不会阻止浏览。DB 需要明确切换，服务端限制会显示错误。每次连接及重新连接后均默认只读，Rust 独立于界面检查写入开关，Redis ACL 仍由服务端执行。多个工作台在隐藏或切换工作区时保留连接和内存中的编辑状态。Cmd/Ctrl+W 隐藏 Redis 视图，不关闭本地终端。“断开”关闭数据库连接及 SSH 进程。“重新连接”建立新连接、保留所选 DB，并在复用内存密码前核对原目标。退出应用释放 Redis 连接及隧道，终端会话仍遵循原有分离行为。

紧凑工作台在工具栏保留连接名、地址、DB 和只读／编辑开关；连接后“重新连接”“断开”直接在工具栏中并排显示，无需展开操作菜单；窄工具栏换行时两个按钮保持在一起。连接信息保留独立菜单。Key 导航默认宽 280 像素，支持鼠标及键盘调整；分组和宽度仅在本次运行内存中保留。工作台可用宽度小于 720 像素时，“浏览 Key”打开抽屉，聚焦搜索框，Tab 导航限制在抽屉内，可用 Escape 或点击遮罩关闭；选中 Key 后自动收起。小窗口可单独滚动详情区。控件、菜单和对话框使用当前界面主题与语言。

## 文件与版本控制

在 Git → 变更中，右键点击“已暂存”或“工作目录”里的文件（或聚焦后按 Shift+F10），选择“回滚文件”，检查路径并确认。此操作将该文件的暂存和工作目录改动一并恢复到 HEAD。新增文件会被删除，包括未跟踪文件和首次提交之前的暂存文件；已暂存的重命名会恢复原路径并移除新路径。确认提示明确说明回滚无法撤销，默认聚焦“取消”。对比和历史视图不提供回滚。拒绝链接、子模块、目录及所选目录外的路径；重命名原路径存在其他变更时，需要先在终端中处理。保留其他文件。

顶部工具栏的分支列表分为 Local 本地分支和 Remote 服务器分支（显示为 `远程名/分支名`）。打开列表时查询所有已配置远程仓库公开的分支，包括尚未获取到本地，以及单分支克隆的获取配置之外的分支；不包含标签和远程 HEAD 符号引用。本地分支定时刷新，并在窗口获得焦点时更新。远程读取显示加载状态和各远程仓库的失败原因，同时保留其他远程的成功结果。远程操作需要网络和已有 Git 凭证；认证失败、超时会显示，再次打开列表可重试。非 Git 目录不显示选择器。游离 HEAD 和尚无首次提交的仓库可以选择已有分支。

选择远程分支时会获取该分支，并创建同名本地跟踪分支，必要时扩展单分支克隆的获取配置。已有同名本地分支只有在跟踪该远程分支时才会复用，否则拒绝切换，不重置分支。选择已有本地分支遵循 Git 的正常切换检查。切换或同步前，编辑器保存并关闭文档；保存冲突保留草稿并阻止操作，直到解决冲突或明确放弃修改。Git 拒绝覆盖文件修改，以及切换到其他 Worktree 占用的分支。不强制切换、不自动 stash、不丢弃文件修改。

在分支控件任意位置右击（或按 Shift+F10）可选择 Push、Pull（仅快进）、Fetch 和刷新分支列表。Push 明确推送到当前分支配置的上游，不强制推送、不自动推送标签。Pull 要求工作区干净，获取上游后仅快进；历史分叉时拒绝操作，不创建合并提交或变基。游离 HEAD、无提交分支或未配置上游时禁用 Push/Pull；请先在终端中设置上游。Fetch 更新所有已配置远程仓库的分支引用并清理已删除的远程引用，不切换或合并分支。刷新分支列表重新读取 Local/Remote。Git 操作在后台线程中串行执行；控件显示执行状态，右键菜单显示完成提示。失败会显示错误，操作后刷新文件、Git 和 GitHub 面板，部分失败也会刷新。菜单支持方向键、Home/End、Enter、Escape 和外部点击关闭，打开时不触发应用快捷键。切换期间阻止重复请求和编辑器跳转，过期响应不会覆盖新分支状态。

## 架构

终端输出通过带有小型 JSON 元数据头的二进制帧跨越桌面到 WebView 的边界。渲染端将接收缓冲区的字节视图直接交给 xterm，不再创建 JSON 数字数组或再次复制输出；消费确认仅保留元数据。桌面端在等待确认前释放原始帧。会话标识、回放尺寸／顺序、输出背压、回滚设置和本地会话服务协议保持不变。格式错误的帧会显示连接错误，并分离受影响的视图。Tauri 内部可能将小型二进制消息编码为 JavaScript 字节数组；大帧使用其二进制 IPC 响应路径。

验证：156 项前端／构建工具测试、40 项后端测试、格式、国际化、TypeScript／生产构建和隔离的 macOS 桌面构建通过。本地会话服务测试完整重跑通过；首次运行遇到间歇性的宿主启动锁冲突。测试覆盖全部字节值、空输出、元数据保留、共享缓冲区解码及错误的帧头。循环包含全部字节值的 1 MiB 样本，原 JSON 帧为 3,743,840 字节，二进制帧为 1,048,667 字节（传输数据约减少 72%）；这不是应用总内存测量。原生 QA（`sh.uterm.desktop.qa.memory`）验证了 10,000 行输出及完成标记、分离后重启应用的历史回放、绿色 ANSI 中文／Unicode 文本、退出码 7 及关闭会话。长期运行内存降幅、真实 Agent 流量和 Windows/Linux 运行验收仍未测量。

文件编辑器及 Markdown/语法依赖按需加载，并显示加载及失败状态。Git 分支轮询结果不变时保留 React 状态引用。PDF 缩略图仅在视口附近渲染，离屏时释放画布缓冲区。开发服务器流式读取本地 PDF 资源，不再将全部资源字节驻留内存；生产包保留完整 PDF 资源以支持离线使用。关键资源生命周期逻辑附有英文及中文注释。

Git 面板在窗口恢复焦点或可见状态时只读取一次快照。所选工作目录／暂存差异在快照读取成功后刷新，包括 Git 状态未变而文件内容改变的情况。窗口隐藏时轮询跳过读取；失败仍显示错误并保留当前差异。目录列表缓存排序键，保留目录优先、名称不区分大小写排序及原始名称的次级排序。区分大小写的文件搜索借用路径和文本行；仅含 LF 的内容跳过换行文本复制，同时保留 CRLF／CR 归一化、Unicode 匹配、行号、忽略规则和搜索限制。终端增量回放一次预分配输出缓冲区，按顺序整块复制保留的输出，保留重置条件、序号、空输出及退出信息。

连接资源控制：Redis 握手期间只预留槽位，不持有连接表锁，其他连接仍可读写或断开；Redis 与数据库各自的八连接上限均计入正在握手的连接，失败自动释放名额。组件下载保留分片，以便中断或取消后续传；离线导入和解压仍使用临时文件，失败或取消会回收。校验使用 64 KiB 缓冲，解压直接读取文件。组件状态通过完成事件更新，不再按秒重复读取和校验驱动；关闭的组件详情及隐藏的未连接工作台不加载组件状态。数据库结果在传输后直接移交，编辑 SQL 不重新渲染未变化的结果单元格。断开时释放已缓存的结果和元数据，SQL 草稿仍保留；隐藏已连接工作台仍保留结果。JSON 序列化共用一个输出缓冲，Redis 十六进制预览最多解码 258 字节。每个数据库进程的临时目录由父进程持有，正常断开或进程异常退出均清理证书临时文件。SSH 一次性密码服务空闲检查间隔为 100 毫秒，销毁时立即唤醒；拒绝指纹后立即结束服务。

资源验证：macOS ARM64、Java 26.0.2.1、`-Xmx192m` 的五次独立进程压力微基准中，200×32 个含中文和控制字符的单元格预热 10 次、序列化 40 次，耗时中位数从 621 ms 降到 103 ms，进程峰值 RSS 中位数从 153,124,864 降到 103,809,024 字节。该合成压力样本用于比较序列化路径，不代表整应用收益。隔离 Release 应用在已连接 TLS MySQL 后的五秒空闲采样中，原生主进程 CPU 约 0.39%、RSS 45.6 MB，JDBC 进程 CPU 约 0%、RSS 21.4–21.5 MB；此快照不含 WebView/会话服务，RSS 会受系统分页影响。每个数据库进程的 Java 堆上限仍为 192 MiB，不包含本机内存；多连接和长时间运行的整进程树峰值仍未测量。

工作区的“数据库”区域支持 MySQL、PostgreSQL 和 Oracle 服务名连接。点击区域加号添加配置，选择后点击“连接”。底部数据库图标独立显示／隐藏该区域，保留连接、SQL 和事务。已连接、忙碌或有草稿的配置不能编辑或移除，引用的 SSH 配置与所属工作区同样受保护。从侧栏打开数据库组件时暂时隐藏项目检查器，返回项目后恢复工具与位置。

配置保存端点、数据库／服务名、用户名、验证证书的 TLS／PEM CA、可选系统 OpenSSH 目标及不透明凭据引用。密码默认仅在内存中保留，“记住密码”存入 macOS 钥匙串或 Windows 凭据管理器。凭据绑定端点、TLS 信任和解析后的 SSH 身份，目标变化需要重新输入。凭据仅通过进程标准输入传递，不进入进程参数或诊断信息。工作区 schema 7 从旧数据升级时保留备份；旧应用会拒绝读取，避免静默丢弃数据库配置。

JDBC 引擎内置于应用（28,972 字节），源码、校验值与 JAR 一起校验。连接时原子恢复缺失或被修改的带版本缓存。主应用构建无需 JDK。Java 与厂商驱动仍为可选组件，不进入主安装包。先验证显式选择的 Java，再从 JAVA_HOME、PATH 和平台目录检测可运行的 Java 17+，最后回退到托管运行时。设置、侧栏及连接窗口均有组件管理入口；缺少组件不会替换 SQL 编辑器。“安装所需组件”显示缺失下载大小，仅安装所选依赖，不自动下载或修改系统 Java。在线／离线安装必须匹配目录中的版本、精确大小和 SHA-256，便携 Temurin 21 使用 TUNA 镜像包。解压限制路径、体积和文件数。中断／取消的下载前缀跨重启保留，继续下载使用经过验证的 HTTP Range，不支持时重新下载；已校验的完整包会保留供安装重试复用，每次复用仍校验目录中的大小和 SHA-256，在线运行时归档直接从保留的缓存校验并解压，离线导入和驱动替换仍使用独立临时暂存文件。临时网络／服务端失败最多尝试下载三次；取消、证书、存储、文件不存在和校验失败不会循环重试。限流及服务端 Retry-After 指引会返回稍后重试提示。每个组件在“离线安装”旁提供“手动下载”。完整包和分片缓存沿用更新缓存的有界清理规则。卸载保留配置，数据库连接存在时禁用。

支持直连、验证证书的 TLS 和已有 OpenSSH 配置。隧道使用限制目标的回环 SOCKS 代理及一次性令牌认证，JDBC 保留原主机名用于证书校验。TLS 使用所选 Java 信任库或指定 PEM CA，不关闭主机名检查。MySQL／PostgreSQL 使用官方 JDBC 驱动，Oracle 使用 JDBC Thin 服务名。暂不支持 SID、Wallet／云预设、任意 JDBC URL、自定义驱动导入或安装服务端。

展开库／模式加载表和视图，系统对象折叠，名称筛选仅搜索已加载对象。双击、Enter 或“查看数据”打开当前表的“数据／结构”视图，不替换 SQL。对象菜单在对应表的操作按钮旁展开，保持在窗口内，靠近底部时向上展开，不受对象树滚动区域裁剪；长列表底部的表也能使用“查看数据”“查看结构”“生成 SELECT”。同一时间只打开一个对象菜单。点击外部、Esc、滚动对象树、调整窗口、窗口失焦或隐藏对象区／工作台会关闭菜单，Esc 返回触发按钮；方向键及 Home／End 可切换操作项。“生成 SELECT”引用实际名称，覆盖未保存草稿前确认。元数据名称中的 `%`、`_` 按字面量处理。每个工作台缓存八组已加载的库／模式，每次元数据最多 500 行。

最多八个 SQL 查询标签分别保留草稿、撤销、选区与结果，限本次运行；所有标签明确共享同一连接及事务。“执行 SQL”默认执行选区或光标语句，范围选择器还提供当前／选中／全部。Ctrl/Cmd+Enter 使用自动范围，Ctrl/Cmd+Shift+Enter 执行全部。每批最多 100 条，顺序执行并在首个错误处停止。语句边界支持 MySQL 字符串／注释、PostgreSQL 美元引号／嵌套注释和 Oracle 替代引号。DELIMITER 脚本与 Oracle 过程块直接拒绝，避免错误切分。带注释 SELECT 和不写入的 WITH 可只读执行，写入型 CTE、锁定语句及 MySQL 含歧义反斜杠引号的字符串需开启编辑。账号权限仍由服务端控制。

补全使用当前方言和已加载的对象／字段。格式化只调整空白，保留标识符大小写、字符串、注释和复合运算符，并提供独立撤销步骤，可处理选区或整个草稿。服务端返回数字位置／行号时支持“定位失败语句”，否则定位语句起点；诊断不返回厂商错误文本或 SQL 值。历史在内存中保留最近 50 次尝试，总 SQL 字符不超过 262,144；恢复时确认替换未保存草稿，可清空历史，不提供重启恢复。每个 SQL 草稿最多 262,144 字符，每标签缓存最近四份结果，单元格字符预算约两百万。断开清除结果，SQL 草稿保留。“复制 SQL”“放弃 SQL 修改”直接平铺，复制保留草稿保护，放弃需确认。“保存 SQL”在文件写入成功后才解除该草稿保护。

可隐藏／调整对象区，使用指针或聚焦后的方向键调整 SQL／结果高度。窄窗口工具栏横向滚动，分页固定底部。滚动时表头与行号保持固定，使用不透明背景遮住下方单元格，避免文字重叠。列宽超出结果视口时，底部显示可拖动的横向滚动条，无需滚动到最后一行即可查看其他列。表格仅渲染可见行列，避免宽表一次创建全部单元格。支持拖动／Shift+方向键选区、整行选择、Ctrl/Cmd+A/C、可带表头的 TSV 复制和列宽调整。双击／Enter 以纯文本查看已加载完整值。NULL 与空字符串不同，截断内容不另行完整获取。“筛选本页已加载结果”仅搜索当前结果及草稿覆盖值；“服务端筛选”则发出参数化表查询，等于、比较、字面子串和 NULL 条件在分页前生效。有主键时按主键排序，翻页重新查询，不保留快照或统计全表。

连接默认只读，此时浏览复用现有进程并在读取后回滚。开启编辑后，仅在需要浏览时额外打开独立只读进程，浏览不会结束 SQL 写入事务；关闭编辑会回收辅助进程。断开关闭两者。八个进程名额包含主连接、辅助浏览与正在打开的连接，可容纳八个只读工作台或四个同时使用两种进程的工作台。辅助浏览故障保留 SQL 连接和事务，重试新建浏览进程。SQL 响应超时／确认丢失时关闭连接并保留草稿。查询服务端超时 30 秒，响应等待上限 40 秒。“取消查询”明确关闭连接；保留连接的驱动取消继续暂缓，避免模糊写入结果。不确定的写入不会自动重试。

开启“允许编辑”后执行其他 SQL 需确认，提交／回滚显式处理共享事务，DDL 可能自动提交。事务指示采用保守策略，编辑模式 SELECT 也标记待处理。可编辑表格要求普通表、非空主键、受支持的标量列及事务支持，MySQL 必须为 InnoDB。视图、无主键、BLOB／CLOB／厂商特殊类型列及非事务表保持只读，任意 SQL 查询结果同样只读。更新不能修改主键／生成列，插入省略生成值。双击可写单元格或点击“编辑单元格”，区分 NULL 和文本，再“暂存单元格修改”；新增行与删除／恢复当前行也先生成草稿。最多 100 行修改，草稿载荷 768 KiB，单值最多 16,384 字符。包含截断值的行不能编辑或删除。

“预览表格修改”展示带占位符的 SQL 与绑定参数。“应用到事务”按主键锁定并比较原始标量值，过期／删除的行或表元数据变化会明确失败。失败只回滚本批保存点，保留草稿及此前 SQL 写入。本批执行预算 25 秒，之后进行有界刷新。成功后显示当前事务数据，仍需“提交事务”；“回滚事务”恢复已提交数据。刷新、服务端筛选、导出及翻页不会覆盖未应用草稿，切换表、断开或放弃需确认。意外断线保留表快照和草稿供核对，重新使用前须重连并确认服务端状态。退出／更新保护覆盖所有 SQL 与表格草稿、进行中的操作和事务，并显示需要处理的隐藏工作台。

CSV／JSON 通过原生保存窗口仅导出已加载页面，输出上限 8 MiB，原子保存。CSV 使用 UTF-8 BOM、字段引用、`\N` 表示 NULL，并防护电子表格公式；JSON 保留字段描述、精确数字字符串、NULL、二进制和截断标记。导出不包含未应用草稿，不查询全表。“执行计划”解释选中／当前的一条只读查询，不使用 ANALYZE；MySQL 使用 EXPLAIN，PostgreSQL 使用 EXPLAIN (FORMAT JSON)。Oracle 需开启编辑且具备 PLAN_TABLE／DBMS_XPLAN 权限，通过保存点移除计划行并保留此前写入。PostgreSQL／Oracle 真实服务验收仍待完成。
