# uTerm 功能说明

[English](features.md) · [环境与命令](../README.md)

## 产品范围

uTerm 是免费的 Windows 和 macOS 桌面终端。所有终端和 Agent 进程均在本机运行。界面支持简体中文和英文。

## 工作区与会话

“关闭会话”在请求终止之前先显示目标工作区及会话，支持其他工作区中的目标。每次只关闭一个会话，关闭失败时保留目标以便重试。回归测试覆盖逐个关闭其他工作区的项目、Worktree、独立终端和聊天会话。原生跨工作区快捷键验收仍待完成。

“下一个会话”和“上一个会话”按存储的工作区顺序跨全部工作区循环切换，每个工作区先遍历项目会话，再遍历独立终端和聊天。跳过空工作区，两个方向均支持首尾循环。切换时同步选中目标工作区、项目及 Worktree，并记住原工作区的选择。没有活动会话时选择当前工作区的首个/末个会话，当前工作区为空则使用全部工作区。编辑器和待处理切换的保护保持有效。回归测试覆盖跨工作区切换、首尾循环、空集合及选择记录；原生快捷键验收仍待完成。

Agent 聊天仅在成功退出（退出码为 0）时自动关闭，确认最后的输出并成功清理本地服务会话后移除聊天窗格与侧栏条目。失败或未知退出状态保留诊断输出，普通 Shell 终端也保留退出输出。关闭会话失败后保留连接，重试必须确认进程终止才能移除；已断开的会话可能需要先重新连接。仅断开连接不会关闭聊天，输出确认或清理失败仍会显示。真实 Claude/Codex 退出验收仍待完成。

关闭会话快捷键每次关闭一个会话：优先所选项目的当前会话及其剩余会话（包括 Worktree），然后按存储顺序关闭其他项目，最后关闭各工作空间的独立会话。未选中项目时，当前独立会话优先。编辑文件时或已无会话时快捷键不可用。顺序测试覆盖逐个关闭全部集合，原生快捷键验收仍待完成。

添加项目支持在原生选择器中多选文件夹。检查所选路径后点击添加，将它们加入确认时选中的工作空间。批量保存之前会校验全部目录，当前空间内已有项目会复用。手动编辑路径会将多选替换为单一路径。原生多选交互仍待运行验收。

欢迎页、命令面板和快捷键的新建聊天使用当前所选项目目录（或所选 Worktree 目录），并归属该项目。未选中项目时使用独立聊天目录。此路径复用项目会话创建流程，真实 Agent 工作目录验收仍待完成。

后台本机会话发现会在每次尝试结束两秒后重试。连接超时不显示错误横幅，其他同步失败仍会显示。超时不会清除已保存的会话。专项自动化测试覆盖超时提示隐藏及其他错误保留；真实超时恢复尚未验证。

工作区包含项目、独立终端和聊天。项目可以包含 Git Worktree。会话支持置顶、排序、分组、取消分组、调整分屏大小和方向聚焦。分组不能跨越项目、Worktree 或独立会话集合边界。

Rust 本地服务负责 PTY 和输出回放。退出应用只分离界面；关闭会话会终止进程。重连保留会话标识并按序确认回放。服务需要认证且仅绑定回环地址。有运行中会话时不会替换其服务程序。

工作区存储接受版本 3；设置接受版本 1，并要求当前字段有效。无效或不支持的数据会显示错误，不覆盖原值。启动只读取本应用的工作区，不导入其他应用的状态。

## 文件与版本控制

文件列表操作错误（新建、重命名、删除、复制、粘贴及在文件管理器中打开）在三秒后消失。每次操作失败重新计时，包括相同错误；保留已输入的名称。目录读取及搜索错误仍保持显示。组件计时测试覆盖自动消失及重复失败；原生计时验收仍待完成。

文件树支持右键菜单“复制/粘贴”，列表获得焦点时支持 Ctrl+C/Ctrl+V（macOS 使用 Cmd+C/Cmd+V）。目录作为粘贴目标，文件以其父目录为目标，空白处以项目根目录为目标。此单条目应用内剪贴板在切换项目及重新打开面板时保留源项目，支持粘贴到其他项目。应用重新加载时清空，不导入系统剪贴板中的文件。源路径和目标路径分别校验各自项目根目录边界，源文件不存在时显示错误。组件与 Windows 后端测试覆盖跨项目复制、冲突、来源缺失及路径越界。支持文件、二进制内容和完整目录，不覆盖已有同名条目。拒绝链接、特殊文件、根目录复制以及复制到自身或子目录。复制在后台线程执行，先在本地暂存内容，限制为 64 层和 100,000 个条目，需要额外磁盘空间。最终写入失败可能留下不完整目标，并显示提示供检查。组件与后端测试覆盖目标定位、递归复制、冲突和路径越界；模拟浏览器预览已检查菜单及刷新后的文件树。原生 WebView 和 macOS 验收仍待完成。

HTML 和 HTM 文件默认以静态预览打开，可切换编辑/预览，未保存文本无需写入磁盘即可预览。保留完整文档 head 样式、内嵌 CSS 和 data 图片。隔离框架禁止脚本、外部或本地链接资源、表单及导航；依赖 JavaScript 的页面（包括 Vite/React 入口 HTML）需要使用项目开发服务器。这类依赖会显示限制说明，避免空白面板没有解释。回归测试覆盖样式保留与活动内容移除。原生 WebView 验收仍待完成。

项目与文件树右键菜单提供“在文件管理器中打开”。目录直接打开，文件在所在目录中定位。文件树路径在打开之前会校验所选根目录边界。原生文件管理器选中效果仍待运行验收。

新建文件、新建目录、文件重命名和目录重命名分别提示冲突原因，包括跨类型的名称占用。重命名为原名称直接成功且不写入，修改输入会清除上一条校验提示。同一父目录下文件与目录仍不能同名。后端回归测试覆盖这些规则，原生交互验收仍待完成。

文件面板底部及悬停提示显示 Windows 路径时省略扩展长度前缀，保留 UNC 服务器/共享路径。内部文件访问路径不变。路径格式测试覆盖盘符与 UNC 路径，原生视觉验收仍待完成。

新建文件和目录在文件树目标目录内行内输入名称，重命名直接编辑原条目。Enter 确认，Escape 取消，失败时保留输入。从目录右键菜单新建时自动展开该目录，刷新保留展开状态。删除仍需明确确认。原生界面的行内焦点与输入法验收尚未完成。

文件访问限制在所选项目根目录内。文本保存检查冲突，并保留未保存草稿以便恢复。Markdown 渲染前经过清理；PDF 画布尺寸设有上限。Git 视图包含状态、差异和提交，并支持 Worktree 管理。GitHub 集成需要用户凭证与访问权限。

## Agent 与设置

Kimi、OpenCode 和 Grok 在 Agent 设置和会话控件中使用内置 SVG 品牌图标，颜色跟随主题，不依赖网络。未知 Agent 保留终端图标。组件测试覆盖不同品牌路径及回退行为，浏览器预览已检查三个图标。原生 WebView 视觉验收仍待完成。

OpenCode 是内置 Agent：从 PATH 及 `~/.opencode/bin` 检测 `opencode` 程序，复用现有项目/聊天启动流程。未找到程序时可打开安装面板。OpenCode、Claude、Codex 和 Gemini 支持确认后通过 npm 全局安装（需要 Node.js/npm 和网络，不自动提权）。仅接受固定包名，安装不占用界面线程，拒绝并发安装，错误保持可见。完成后刷新程序检测；自定义 npm 安装位置可能需要配置可执行文件路径或重启 uTerm。Kimi 提供官方安装说明；Grok 与自定义程序需要按发布方说明手动安装并配置路径。OpenCode 暂不提供 Hooks 或用量集成。双语组件测试覆盖确认、失败重试与刷新；后端测试覆盖安装包白名单。实际软件包下载、原生 Agent 启动及 macOS 安装仍未验证。

点击休息提醒内部或外部空白处、按 Escape 均不会关闭提醒。只能点击“继续使用”手动关闭，或等待十秒自动关闭。组件交互与计时器测试已覆盖并通过这些路径；原生 WebView 交互仍未验证。

通用设置中，休息提醒开关与间隔输入框位于同一行，不显示自动关闭说明文字。提醒计时与输入校验保持不变。浏览器预览已检查行内对齐，双语组件测试检查两个控件及说明文字移除。

设置 → 通用提供休息提醒开关（默认关闭）及 1–1440 整数分钟的间隔（默认 60）。间隔编辑在离开输入框时保存。应用运行期间，非阻塞提醒不抢焦点，显示十秒后自动关闭，也可点击“继续使用”关闭。关闭后重新计时，修改间隔或重启应用也会重新计时。关闭功能会取消待触发提醒。休眠期间错过的间隔不会排队补发，应用不会强制切到前台。计时器及设置回归测试覆盖自动/手动关闭、清理与无效值；原生计时与视觉验收仍待完成。

设置 → 通用 → 开机自启动控制 Windows 和 macOS 登录系统后自动启动。打开设置时读取系统注册状态，不会自动开启。修改立即生效，失败提示保持可见并可重试。恢复界面设置不会改变系统自启动注册。开发版使用独立的启动项。模拟组件测试覆盖开启、关闭及失败恢复。独立浏览器预览已检查通用设置布局；原生登录启动和 macOS 验收仍待完成。

Agent 定义指定程序及参数列表。Hooks 上报活动；启用时，用量可组合本地日志与服务商请求。可用性取决于服务商凭证和权限。终端输入及进程 I/O 与界面渲染分开处理。

设置包含外观、配色主题、字体、终端光标和滚动行数、快捷键、默认 Shell 与 Agent。主题导入仅接受支持的颜色字段。

Windows 终端获得焦点时，Ctrl+C 复制选中的终端文本；未选中文本时仍作为终端中断键。Ctrl+V 和 Ctrl+Shift+V 粘贴剪贴板文本，并在终端启用时使用括号粘贴模式。Ctrl+Shift+C 也可复制选中文本。macOS 的 Cmd+C/Cmd+V 通过原生复制/粘贴事件交给 xterm，不请求浏览器异步剪贴板访问：粘贴无需额外点击 WebKit 的“Paste”，也不会产生该接口的 `NotAllowedError` 横幅。Control 按键仍保留给终端程序。原生粘贴保留括号粘贴处理和禁用输入保护。其他剪贴板及会话失败仍会显示；若连接已关闭或改变，尚未完成的异步粘贴会被丢弃。快捷键回归测试覆盖 macOS 原生事件路由、选择状态及 Shift 修饰键，以及 Windows 复制/粘贴和 Control 透传；原生验收情况见下文。

## 界面

左右边栏均可向各自的窗口外侧边缘拖动，目标宽度达到 30 像素或更小时亮起吸附提示，只有松开鼠标才隐藏；按住拖回阈值外可取消吸附。右侧栏在限制最小宽度之前检查此阈值，记住当前面板，可通过按钮或快捷键恢复。松手隐藏后恢复拖动前宽度供下次展开，取消指针操作只清理提示且不隐藏。仅调整窗口大小不会触发收起。边界测试覆盖两侧；右侧栏原生拖动验收仍待完成。

左侧栏显示/隐藏使用 Windows Ctrl+B、macOS Cmd+B；右侧栏使用 Ctrl+Alt+B 或 Cmd+Option+B。两项均出现在设置 → 快捷键与命令面板中，可自定义或禁用。右侧栏恢复上次面板（所需项目不可用时回退到文件），需要存在工作目录。对话框打开或编辑器正在等待切换确认时不触发快捷键。自动化测试覆盖默认值、冲突和自定义绑定；原生终端快捷键验收仍待完成。

侧栏隐藏按钮位于顶部品牌行最右侧。拖动右边缘可调整宽度，下限为 30 像素，上限取 320 像素与窗口宽度 30% 的较小值（最低仍为 180 像素）。向左拖到 30 像素或更小时显示吸附提示，松手隐藏，可通过工具栏按钮重新展开。宽度在当前应用运行期间保留。分隔条还支持方向键、Home 隐藏、End 最大宽度及 Enter/双击恢复默认。边界测试覆盖收起阈值与窄窗口上限；原生鼠标交互验收仍待完成。

中栏错误横幅在 1.5 秒后隐藏，不清除内部错误状态。不同消息会重新计时，未改变的后台错误不会反复弹出。横幅隐藏后仍保留工作区读取重试入口。原生界面计时验收仍待完成。

设置、命令面板和 Agent 窗口支持在边界外按下并完成主指针点击时关闭。内部点击和从内部开始的拖动不会关闭窗口。更新安装期间设置窗口不能关闭。边界测试覆盖内外坐标，原生指针交互仍待验收。

设置 → 通用可即时切换简体中文和英文，覆盖已打开面板、菜单、命令搜索、校验消息、无障碍标签和编辑器搜索控件。切换语言不会重建终端会话或替换编辑器文档。应用自身的后端诊断在显示时翻译；未知系统/服务商输出、终端内容、文件名和用户填写的名称保留原文。原生系统对话框控件使用系统语言，项目目录选择器标题跟随应用语言。

缺失翻译键会显示明确的诊断标记并输出去重的控制台错误，不再静默返回中文。`pnpm i18n:check` 拒绝未登记的中文源码字面量、未翻译的 JSX 文本/无障碍属性及字面量键的错误参数。测试验证全部已登记译文与占位符一致性、检查器反例、即时语言订阅、设置全部八个标签及主要面板的双语渲染。源码分析和模拟组件测试用于防止回归，不代表所有动态状态或原生运行状态均已验证。

设置 → 外观 → 界面主题提供暗黑（黑色与银灰，默认）、砂岩（暖灰与砂金）、深海（深蓝与冰蓝）、青苔（墨绿与薄荷）、纸白（暖白与陶棕）、晴空（冷白与天蓝）六套预览卡片。纸白与晴空固定使用浅色界面，不改变终端颜色模式偏好；其余四套支持深色、浅色和跟随系统。选择后即时生效并自动保存，不改变终端配色选择，也不重建会话。缺少界面主题字段时默认使用暗黑；无效值会被拒绝。

界面采用暖炭灰表面、克制的砂金强调色、细分隔线和紧凑控件，并提供对应的浅色配色。侧栏选择、终端窗格焦点和工具面板标签使用一致状态。欢迎页提供项目、终端和聊天入口及已配置快捷键提示，不可用操作会禁用。空工具面板不占用屏幕空间。界面颜色和终端 ANSI 配色相互独立，并遵循减少动态效果偏好。设计变量和参考来源见 [DESIGN.md](../DESIGN.md)。

## 架构

文件编辑器及 Markdown/语法依赖按需加载，并显示加载及失败状态。Git 分支轮询结果不变时保留 React 状态引用。PDF 缩略图仅在视口附近渲染，离屏时释放画布缓冲区。开发服务器流式读取本地 PDF 资源，不再将全部资源字节驻留内存；生产包保留完整 PDF 资源以支持离线使用。关键资源生命周期逻辑附有英文及中文注释。

React 组件位于 `src/components/`，状态和纯逻辑位于 `src/lib/`，Tauri 命令位于 `src-tauri/src/`，PTY、回放和 hooks 位于 `crates/utermd-local/`。后端和会话服务各自使用独立的 Cargo 清单和锁文件。

## 验证与限制

macOS 剪贴板验证：137 项前端及构建工具测试、锁定依赖安装、格式、文档和国际化检查、TypeScript/生产构建及独立桌面调试构建通过。使用 `sh.uterm.desktop.qa.clipboard` 包标识的原生 QA 窗口中，已观察到中文直接粘贴到 Shell，没有 WebKit“Paste”确认或 `NotAllowedError` 横幅。未重启已安装的应用。原生复制、多行粘贴和真实 Agent 剪贴板验收仍待完成；未在 macOS 上重新验证 Windows 或 Linux 的运行行为。现有大代码包及 Rust 未使用代码警告仍存在。

Windows 文件复制验证：135 项前端测试、32 项后端测试、TypeScript、生产构建及国际化检查通过。浏览器预览模拟文件系统命令，原生集成仍未验证。生产构建仍有大代码包警告。
