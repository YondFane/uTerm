## 产品范围

uTerm 是 Windows 和 macOS 桌面终端。本地终端和 Agent 进程在本机运行，SSH 远程 Shell 在服务器运行。

界面支持简体中文和英文。

## 项目官网

### 官网预览

`site/` 中独立的 GitHub
Pages 官网介绍终端与 Agent、项目与 Git、SSH/SFTP 和 Redis／数据库。四个标签明确标注为使用示例内容的界面示意，不连接真实桌面会话或服务器。

六种界面配色仅改变预览。简体中文／英文切换更新正文、无障碍标签、页面元数据及文档链接；浏览器禁止存储时仍可切换。

标签支持方向键、Home 和 End 导航。

### 仓库指南与展示素材

仓库首页使用英文 README，语言链接打开 `README.zh-CN.md`；`README.en.md`

### 下载与安装命令

Intel 下载入口初始指向 GitHub 稳定版发布页。公开的最新发布 API 成功时，解析为本仓库该版本对应的安装包；缺少资源、请求限流或网络失败时保留发布页入口。

## 安装

### 稳定版本

仓库侧栏的 Latest 入口指向稳定安装包版本。发布流水线在公开下载验证和稳定更新清单发布成功后，才将版本标记为 Latest。

预发布更新通道不会标记为 Latest。

发布技能要求说明以 `# uTerm MAJOR.MINOR.PATCH`
开头，其后为逐项对应的中英文功能点与使用教程。发版前核对标题版本与应用版本、说明文件名及发布标签一致；发布后还需检查 Release 正文和稳定更新清单中的版本标题。

用户授权的稳定版本通过 CI、公开下载、稳定清单及 Latest 验收后，发布技能要求将本次已发布提交合入
`main`
并推送。保留双方历史，排除后续未发布提交，并核对远端祖先关系。分支保护或冲突尚未解决时，明确保留同步未完成状态。

- macOS 发版准备检查通过：锁定依赖安装、274 项前端／构建工具测试（10 项跳过）、113 项后端测试（9 项忽略）、46 项宿主测试（2 项原生 CLI 测试忽略）。TypeScript／生产构建、桌面编译、全仓格式、国际化及文档检查通过。这些检查不代表 Windows／Linux 运行验收完成。

### 一行命令安装

[README](../README.zh-CN.md#一行命令安装) 提供终端和 PowerShell 一行安装命令，对应
`scripts/install/install.sh` 和
`scripts/install/install.ps1`。脚本读取对应平台的稳定更新清单，并通过 HTTPS 从本仓库下载匹配版本的安装包。

macOS 自动选择 Apple Silicon 或 Intel（包括 Rosetta 检测），只读挂载 DMG，安装到
`~/Applications/uTerm.app`，不使用 sudo，也不启动应用。保留已有用户级／系统级安装，请使用应用内更新。

Windows x64 打开安装向导，并报告非成功退出码。安装包最多尝试下载三次。

稳定更新清单提供安装包大小和 SHA-256 时，中断下载保留并续传，完整缓存重新校验后复用；旧清单仍可使用，但每次重新下载，不持久复用安装包。挂载和暂存临时文件会清理；已校验的安装包缓存最多保留四个文件，后续使用时清理超过七天的非当前文件。

Windows 使用缓存锁；macOS 使用锁目录，强制终止后可能需要手动移除残留锁目录。失败时输出官方手动下载页。

需要访问 GitHub，无需开发工具链。应用未经 Apple 公证，首次启动可能需要在“隐私与安全”中批准。

远程命令需要脚本已发布到 `release`。

### npm 安装命令

`scripts/install` 中的独立 npm 包通过 npx、pnpm dlx 或全局安装提供 `uterm-install`
命令，需要 Node.js
22.13 或以上。命令以独立参数调用包内平台脚本，不使用 Shell 插值，并保留安装器退出码。

帮助及无效参数不会启动安装。包不使用安装生命周期钩子；安装／移除 npm 包只管理命令，不安装／卸载桌面应用。

包已以 `@yondfane/uterm-install` 名称发布到 npm。

## 工作区与会话

### 项目与 Worktree 条目

项目和 Worktree 行在悬停或聚焦时保留文件夹图标，不显示独立下拉按钮。行内操作显示新建终端和已启用的 Agent，不显示“更多操作”省略号按钮；右键点击行仍可打开原有菜单。

行内空间不足时，终端／Agent 按钮组浮到该行右侧，可以伸出侧栏，保留文件夹图标和名称的空间；较宽的行仍在行内显示按钮组。

左键点击图标、名称或行标签剩余空白处可展开／折叠子项；聚焦该行后按 Enter／空格执行相同操作。原有项目／会话选择及编辑器切换保护继续生效。

右键菜单、拖动和行内快捷操作按钮不会触发折叠。活动树折叠状态保留在本次运行内存中，非活动项目／Worktree 仍沿用已保存的折叠设置；折叠后仍显示使用状态圆环。

### 连接右键菜单

右键点击 SSH 连接行，可使用“新建 SSH 终端”和“编辑 SSH 连接”；右键点击 Redis 或数据库连接行，可编辑该连接配置。这些操作不再以行内加号／省略号按钮显示，区域添加按钮和行尾移除按钮保留。

打开菜单不会选中或连接目标；已有会话、传输、连接和草稿保护仍会禁用编辑。聚焦连接行后按 Shift+F10 或菜单键可打开菜单，方向键与 Home／End 切换可用操作，Escape 关闭并将焦点返回连接行。

菜单保持在窗口内；点击外部、滚动、调整窗口、窗口失焦、隐藏／折叠区域、切换工作区或移除目标时关闭。

### 资源使用状态圆环

侧栏的项目、Worktree、SSH、Redis 和数据库图标在使用时保留原本颜色，仅外围圆环与柔和光晕显示绿色。项目计入全部未关闭的终端／Agent 会话，包括 Worktree 中的会话；每个 Worktree 只计入自身会话，SSH 配置计入未关闭的 SSH 会话。

- 空闲或已退出但尚未关闭的会话仍计入。仅存在而没有会话的 Worktree、仅选中的配置不会亮起。

- Redis 和数据库必须已成功连接；仅处于连接中、已断开、忙碌或有未保存修改的状态不会亮起。最后一个会话关闭或连接断开后熄灭，项目折叠后仍显示；浅色模式使用更深的绿色。

- 无障碍描述说明存在未关闭会话或已连接。此常亮指示与会话图标上未读完成提示的闪烁效果相互独立。

### 区域折叠与批量操作

侧栏各区域标题（包括活动、已固定、SSH、Redis、数据库和项目）支持点击名称、箭头或标题行剩余空白处，在标题完整高度内均可独立展开／折叠区域。聚焦标题后按 Enter／空格执行相同操作。

- 右侧添加、数据库组件及全部展开／折叠按钮独立执行，不切换区域折叠状态。区域默认展开；折叠状态在本次应用运行内保留，使用底部按钮隐藏再显示区域后也会保留。

- 折叠只收起侧栏条目，保留 SSH 会话、已连接的工作台、选中项、草稿和事务。折叠后仍可使用添加按钮及数据库组件管理。

- 全部展开／折叠按钮仅在所属区域存在项目或 Worktree 文件夹时显示；“项目”区域为空时保留标题和“添加项目…”入口。

## SSH 与远程文件

### 连接配置

侧栏中的 SSH 连接属于当前工作区。添加连接时可填写主机地址、端口（默认 22）、用户名、远端系统（Linux/macOS 或 Windows）和可选文件根目录。

- 选择“主机地址”或“OpenSSH 配置”，认证默认使用 OpenSSH 自动选择。“更多设置”包含可选连接名称、远端系统和文件根目录；名称留空使用主机名。“仅保存”只保存配置，“保存并连接”先保存再新建终端。保存失败不会授权新的登录。

- “查看生效配置”调用系统客户端解析配置，不建立远程登录，显示实际用户名、地址、端口及是否配置跳板机或代理。明确填写的用户名和端口覆盖继承配置，别名模式中留空则继续继承。

- 用户名留空使用 OpenSSH 配置或本机账户，根目录留空使用服务端登录目录。Host 别名模式保留已有配置，读取
  `~/.ssh/config` 及 Include 文件，不改写原文件；别名模式中端口和用户名留空时继承 OpenSSH 配置。

- 认证支持 OpenSSH 自动选择、私钥文件/ssh-agent，以及在连接窗口输入密码。需要系统已安装 OpenSSH；Windows 可安装 OpenSSH 客户端可选功能。

- 这些连接选项不捆绑 SSH 可执行文件、JVM 或新增运行时依赖。

### 快速连接与主机搜索

在 SSH 侧栏选择**快速 SSH 连接**，输入 Host 别名、`user@host:port` 或
`ssh://user@host:port`。带端口的 IPv6 地址需要方括号，例如
`user@[::1]:2222`。单独的别名继承 OpenSSH 配置，明确地址默认端口为 22。拒绝命令、内嵌密码、URL 路径和无效端口。

快速连接在终端使用 OpenSSH 自动认证，主机显示为“临时”。本地配置会为重开应用后的附着保留；关闭最后会话且释放文件通道、文件标签、传输和隧道后，自动移除临时连接。
**保存为常用连接**保留配置，不改变已有会话。用于 Redis 或数据库隧道前，需要先保存为常用连接。

**搜索 SSH 主机**按名称、地址和用户名筛选当前工作区的主机，忽略大小写。清空搜索后恢复全部主机；筛选保留已有会话和连接。

### 跳板机

在**更多设置 → 跳板机（可选）**中选择 OpenSSH 别名，或填写一台跳板机的地址，例如
`ops@bastion:2222`。留空时继承 OpenSSH 配置。生效配置预览包含跳板机设置，不建立登录。

终端、SFTP、端口转发和 Redis 隧道使用同一跳板机设置。跳板机通过自己的 OpenSSH 配置或 ssh-agent 认证，目标机保存的密码或专用私钥不会自动用于跳板机。密码模式不支持跳板机。多级跳转和 ProxyCommand 可通过已有 OpenSSH 别名配置。旧会话后台需要先安全重启，才能创建带有明确跳板机设置的会话。

### 本地端口转发

从 SSH 连接标题打开**端口转发**，填写本地端口、远端地址和远端端口，然后选择**添加转发**。规则随连接保存，只有点击**启动转发**后才启动。远端地址由 SSH 服务器访问，因此
`127.0.0.1` 指该服务器；本地监听只绑定 `127.0.0.1`。

启动中、监听中、失败和已停止状态独立于终端及 SFTP 显示。监听中只确认本机 SSH 监听已建立，不代表远端服务可用。
**停止转发**释放进程和端口，运行中的规则不能移除。隐藏面板保留转发；退出应用停止转发，重开应用不会自动重启。终端附着继续遵循原有生命周期。

打开端口转发时收起远程文件面板，文件连接继续保留；打开远程文件时收起转发面板，运行中的转发继续保留。

- 每个连接最多保存 16 条规则，同一连接内的本地端口不能重复；应用最多同时运行 16 个转发。端口范围为 1–65535。端口占用及认证失败会明确显示，启动最多等待 60 秒。
- 自动／密钥认证需要可信主机及非交互密钥／ssh-agent，密码认证沿用已有密码和指纹策略。启动或转发期间禁止编辑和移除连接。
- 支持本地 TCP 转发，暂不提供远端转发、动态 SOCKS 转发和自动启动。此面板拒绝已包含 OpenSSH 转发规则的配置，需使用不含这些规则的别名，避免打开非预期监听。

### 连接工作区

选择主机时返回本次应用运行中上次选中的会话；没有会话时显示连接概览，列出远端系统、认证方式和文件根目录。选择主机不会建立 SFTP 连接。

连接标题区域显示当前会话的目标、生效地址、终端进程状态与文件连接状态，并就近提供“新建 SSH 终端”“远程文件”和“编辑 SSH 连接”。连接仍有会话、文件连接、保留的文件标签、传输或依赖工作台时，继续禁止编辑。

终端状态只说明本机 SSH 进程或附着状态，不代表服务端认证已完成。主机指纹及交互认证提示仍需在终端完成。已结束会话保留旧输出；重新附着恢复已有本机附着，新建终端则建立新的远程登录。

### 密码与主机验证

密码默认仅在本次应用运行期间有效；勾选“记住密码”后存入 macOS Keychain 或 Windows Credential
Manager，工作区和会话数据只保存不透明引用。编辑时密码留空可保留现有密码，也可切换临时内存与系统凭据库保存方式。

密码绑定连接及解析后的目标，目标变化后需重新输入。保存失败只回滚新建凭据，保留原配置。

凭据库中的密码不会返回前端，也不会进入进程参数、环境变量、工作区文件或日志。短期有效且需认证的回环辅助程序通过 OpenSSH
askpass 提供一次密码，并复用应用自身可执行文件。

密码模式支持普通密码认证，未知主机指纹通过原生对话框确认；拒绝 ProxyJump/ProxyCommand、验证码及修改密码提示。自动/密钥模式保留 OpenSSH 跳板机行为；有口令的私钥用于文件或隧道前需加入 ssh-agent。

### SSH 会话生命周期

每个连接支持多个终端会话，以及同一连接内的置顶、排序和分屏。SSH 使用现有本地 PTY 服务，保留终端输入、尺寸同步和输出回放。

自动/密钥模式在终端确认主机指纹和处理交互认证；密码模式使用连接中配置的密码并通过原生对话框确认指纹。退出应用时分离界面，本机 SSH 进程继续运行；关闭会话终止该 SSH 进程，远程进程是否继续取决于服务端。

重新打开应用会附着已有会话，不会静默启动新的网络登录。“重新启动”创建新会话，并保留旧输出。

网络故障后不恢复原远程 Shell；持续运行的服务端任务需要 tmux 等工具。旧后台服务需要先关闭其会话并安全重启，才能启用 SSH。

### 打开远程文件

打开“远程文件”后，点击“连接文件”才会使用该配置的主机、端口、用户名和认证方式建立 SFTP。连接进度和错误与终端状态分别显示。隐藏面板保留缓存连接；“断开文件连接”经过编辑器保存保护后，只释放文件通道。“重新连接”也经过保存保护，并保留先前解析的目标和根目录作为预期目标。选择主机或断开文件都不会自动建立登录。

自动/密钥模式需要可信主机及密钥/ssh-agent 非交互认证；未知主机应先在 SSH 终端确认。

密码模式也可通过原生对话框确认新主机。文件根目录独立于 Shell 中的
`cd`；Windows 根目录必须位于本地盘符下，不支持 UNC 共享。

暂不提供远程 Git、GitHub、本地目录工具、全目录搜索、目录传输、递归删除和断点续传。

### 远程根目录内的编辑

文件树支持隐藏文件、文本编辑、受支持的图片/PDF 预览、新建文件/目录、重命名，以及删除文件或空目录。文本继续遵循 2
MB 上限、UTF-8/BOM 和换行处理，并保留冲突检查、保存/关闭保护及本机恢复草稿。

文件身份包含 SSH 连接、解析后的目标与规范根目录，配置变化后草稿不会静默写向另一台服务器。符号链接读取限制在根目录内，拒绝通过链接修改文件。

路径按远端规则处理，不展示名称含反斜杠、冒号或控制字符的远程文件。

### 安全保存与冲突

保存使用同目录临时文件、内容版本检查及服务端的 `posix-rename@openssh.com`
扩展，不以先删除原文件的方式降级覆盖。服务器不支持安全替换时，允许读取、下载和上传新文件，已有文件以只读方式打开。

可用时保留普通权限位；uTerm 不保留 Windows
ACL。冲突检查采用乐观校验，不能阻止其他服务端程序并发写入。

提交后发生网络故障时，结果可能不确定；应保留草稿并重新读取，再决定是否重试。

### 文件传输与连接保护

可从工具栏或目录右键菜单上传文件，从普通文件的右键菜单下载到原生保存对话框选择的位置。传输分块流式处理，显示字节进度、完成、错误与取消状态。

- 上传覆盖默认关闭，需要明确勾选；拒绝目录与链接传输。取消时尝试清理临时文件，断线时可能留下需要手动清理的
  `.uterm-*` 临时文件。

- 有传输进行时退出，会先提供等待或取消传输的选择，再经过编辑器保存保护。传输期间不能安装更新。

- 最多同时传输四个任务、缓存十六个远程文件连接；“重新连接”释放该连接此前的文件通道。连接仍有会话、保留的文件标签、进行中的传输、正在启动／运行的端口转发，或依赖它的 Redis 工作台已连接、忙碌或有草稿时，禁止编辑和移除。

- 移除前还需移除依赖的 Redis 配置。保存空闲 SSH 配置时同步更新依赖的 Redis 配置；已记住的 Redis 凭据仍绑定原目标。

- 已有会话保留原目标。

## Redis 连接与工作台

### Redis 连接配置

Redis 连接属于工作区。从侧栏添加名称、地址、端口、数据库编号和可选 ACL 用户名/密码。

- “测试连接”执行认证和 PING 后释放临时连接。恢复配置时不会自动连接。

- 支持 TCP 直连、TLS，以及从现有 SSH 连接中选择的系统 OpenSSH 隧道。隧道模式由 SSH 服务器访问 Redis 地址；`127.0.0.1`
  指该服务器。

- 隧道复用所选配置的主机、端口、用户名和自动/密钥/密码认证，并需要 TCP 转发权限；继续兼容只有别名的旧 Redis 配置。密码模式的主机确认和凭据有效期遵循 SSH 配置。

- SSH 选择器引用已保存配置，并包含跳板机设置。打开 Redis 连接编辑器或选择工作台时解析当前配置；保存空闲 SSH 配置时也会更新依赖的 Redis 设置。活跃工作台在断开前保留受保护的原目标，临时 SSH 连接需先保存。Redis 单独管理隧道进程，独立于终端、SFTP 和本地端口转发进程。

- TLS 也可用于隧道内部，始终验证 Redis 服务端名称；可选 PEM
  CA 证书及服务端名称覆盖，CA 留空时使用系统信任。不提供双向 TLS。

### 只读模式与连接生命周期

工作台在权限允许时显示服务端版本、角色及 PING 延迟，部分信息不可用不会阻止浏览。DB 需要明确切换，服务端限制会显示错误。

每次连接及重新连接后均默认只读，Rust 独立于界面检查写入开关，Redis
ACL 仍由服务端执行。多个工作台在隐藏或切换工作区时保留连接和内存中的编辑状态。

Cmd/Ctrl+W 隐藏 Redis 视图，不关闭本地终端。“断开”关闭数据库连接及 SSH 进程。

“重新连接”建立新连接、保留所选 DB，并在复用内存密码前核对原目标。退出应用释放 Redis 连接及隧道，终端会话仍遵循原有分离行为。

### 工具栏与窄窗口布局

紧凑工作台在工具栏保留连接名、地址、DB 和只读／编辑开关；连接后“重新连接”“断开”直接在工具栏中并排显示，无需展开操作菜单；窄工具栏换行时两个按钮保持在一起。连接信息保留独立菜单。

- Key 导航默认宽 280 像素，支持鼠标及键盘调整；分组和宽度仅在本次运行内存中保留。工作台可用宽度小于 720 像素时，“浏览 Key”打开抽屉，聚焦搜索框，Tab 导航限制在抽屉内，可用 Escape 或点击遮罩关闭；选中 Key 后自动收起。

- 小窗口可单独滚动详情区。控件、菜单和对话框使用当前界面主题与语言。

### Key 搜索与刷新

glob 规则，不自动添加通配符；按 Enter 或点击搜索开始新扫描。“刷新 Key”按当前输入重新扫描，同时保留所选详情和草稿，即使本批扫描未返回该 Key。

分组数字表示已加载数量，不代表数据库总量。底栏区分扫描未完成／完成、空批次及 10000 个 Key 上限；游标归零前，空批次仍可继续加载。

### 集合浏览与草稿

Hash 浏览在下方独立区域打开字段，保留当前成员批次和匹配规则；切换字段、搜索／翻页成员、重新读取及关闭字段编辑区均保护未保存修改。字段保存成功后更新已加载行；首次新建 Hash 数据后读取服务端成员数及 TTL，并保留已保存字段。

List 表格显示索引／值，Set 显示成员，ZSet 显示成员／分数；按范围读取的集合支持前后翻页。String 元数据显示字节数，集合显示成员数，字段显示值的字节数，不将其标作 Redis 内存占用。

TTL 明确显示时长或“无过期时间”，悬停可查看读取时的毫秒值。新建 Key、添加字段、重命名和 TTL 修改使用对话框；删除操作明确显示连接、DB 和目标，创建对话框先打开未保存的值草稿，点击保存才写入；重命名、TTL 及删除对话框使用一次最终确认。

对话框和字段编辑区关闭后将焦点返回入口。二进制 Key 保留原始字节，仅文本名称提供复制操作；二进制和超大值继续使用有界只读预览。

命令台默认折叠，仍仅接受已登记的只读命令。

### 扫描与值大小限制

Key 使用游标式 SCAN，COUNT 提示值为 200，支持 glob 匹配、去重及冒号分组。空批次会立即返回，不发起元数据请求或触发超时，也不代表扫描完成，需要继续至游标为零。

- 每个工作台最多保留 10000 个 Key，达到上限后需要缩小匹配范围。String 支持 1
  MB 字节区间预览，完整值是有效 UTF-8 且不超过 1 MB 时可编辑。

- Hash 支持增量浏览和单个字段编辑。List 和 ZSet 每页读取 200 个成员；Set 和 Hash 使用游标扫描及成员匹配。

- 集合单元格最多预览 64
  KB；异常大的扫描批次会标记部分显示，需缩小匹配范围。Key/字段名限制为 4096 字节。

- 二进制 Key 保留原始字节身份，无效 UTF-8 值显示十六进制预览。协议读取预算为 16
  MB，过大响应会关闭连接，避免无限保留返回数据。

### 二进制与 Java 序列化预览

二进制 String 值和单个二进制 Hash 字段在前 256 字节的十六进制预览下方显示序列化信息。Java Object
Serialization 预览识别流版本，以及可读取的首个普通类描述、serialVersionUID 和字段名/类型；展开“字段信息”可查看字段。

- 可读 UTF-8 文本保留可见字符串，控制字符显示为 ·，无效字节显示为 �，最多处理当前页前 64
  KB。元数据最多检查 256 个字段，每个名称/类型字符串最多 4096 字节。

- 截断或暂不支持的描述保留已识别信息并提示部分显示；后续 String 分页不推断流头。该视图保持只读，不还原完整对象、继承/嵌套类描述或自定义编码，无需 JVM 或额外运行时依赖。

### 编辑与写入保护

开启编辑后，可新建 String、Hash、List、Set 或 ZSet，修改 String 或单个 Hash 字段、删除 Hash 字段、不覆盖已有 Key 地重命名、删除 Key，以及设置/清除 TTL。保存通过连接内串行的 WATCH/读取/比较/MULTI/EXEC 检查冲突，拒绝已变化或消失的原值。

新建 List、Set 或 ZSet 时，点击“新 Key”，输入名称并选择类型，再点击“新建”打开首个成员的草稿。填写值后点击“保存”才创建 Key。空值是有效成员；不提供不含成员的空集合创建。已有 Key 不会被覆盖。

- 使用成员表上方或行内的“添加成员”“编辑成员”和“删除成员”。List 支持在开头或末尾添加，修改和删除按界面显示的从零开始的索引定位，重复值也保持位置正确。Set 编辑替换一个成员；ZSet 可修改成员、分数或两者，分数接受可表示的有限十进制数和科学计数法，拒绝会下溢为零的非零值。添加或替换 Set/ZSet 成员时，目标成员已存在会拒绝操作。

- 添加和编辑先打开草稿，点击“保存”才写入；只修改分数也属于未保存修改。切换成员、翻页、关闭编辑区、切换目标、断开及退出时，均提供保存／放弃／取消保护。保存失败保留值和分数。删除成员使用一次确认，展示连接、DB、Key 及成员／索引；删除最后一个成员会同时删除 Key。

- List 按索引修改和删除会比较完整快照，限制为最多 10000 个成员、全部值合计不超过 1
  MB。更大的列表仍可浏览及在开头／末尾添加。Set 核对原成员，ZSet 还核对原分数。添加、修改以及删除成员后 Key 仍存在时，保留集合已有 TTL。

- 表格 64
  KB 预览中完整的有效 UTF-8 成员可编辑；二进制或截断预览不可编辑。完整的二进制成员可删除。每个新成员值最多 1
  MB。写入成功后重新读取集合并刷新 Key；Set 的筛选条件和 ZSet 的排序可能使修改后的成员位于当前批次之外。

- 已有 String 保存时保留当前 TTL，需要服务端支持 KEEPTTL。保存失败保留草稿。

- 写入超时会关闭连接并提示结果未知，需要重新读取再决定是否再次写入，不会自动重放写请求。删除 Key 及名称/TTL 修改需要确认。

- 命令台仅接受 PING、限定 INFO 分区、DBSIZE、TYPE、TTL/PTTL、EXISTS 和长度命令，不执行任意命令。暂不提供 Cluster/Sentinel 发现、订阅、Monitor、脚本、批量导入导出及 Stream/模块专用视图。

### 回滚单个文件

在 Git
→ 变更中，右键点击“已暂存”或“工作目录”里的文件（或聚焦后按 Shift+F10），选择“回滚文件”，检查路径并确认。此操作将该文件的暂存和工作目录改动一并恢复到 HEAD。

- 新增文件会被删除，包括未跟踪文件和首次提交之前的暂存文件；已暂存的重命名会恢复原路径并移除新路径。确认提示明确说明回滚无法撤销，默认聚焦“取消”。

- 对比和历史视图不提供回滚。拒绝链接、子模块、目录及所选目录外的路径；重命名原路径存在其他变更时，需要先在终端中处理。

- 保留其他文件。

回滚在后台线程执行，与分支操作串行。操作前编辑器保存并关闭该目录的缓存文件；保存冲突会保留草稿，并通过现有的重试／放弃／取消流程阻止回滚。

保存等待期间切换仓库会取消延迟回滚。文件状态或 HEAD 改变时拒绝请求。

完成后刷新文件、Git 和 GitHub 面板，失败提示在后台刷新后仍保留。

### 本地与远程分支

### 切换分支

选择远程分支时会获取该分支，并创建同名本地跟踪分支，必要时扩展单分支克隆的获取配置。已有同名本地分支只有在跟踪该远程分支时才会复用，否则拒绝切换，不重置分支。

选择已有本地分支遵循 Git 的正常切换检查。切换或同步前，编辑器保存并关闭文档；保存冲突保留草稿并阻止操作，直到解决冲突或明确放弃修改。

Git 拒绝覆盖文件修改，以及切换到其他 Worktree 占用的分支。不强制切换、不自动 stash、不丢弃文件修改。

### 推送、拉取、获取与刷新

在分支控件任意位置右击（或按 Shift+F10）可选择 Push、Pull（仅快进）、Fetch 和刷新分支列表。Push 明确推送到当前分支配置的上游，不强制推送、不自动推送标签。

- Pull 不要求工作区干净，获取上游后仅快进。保留无冲突的已暂存、未暂存修改及未跟踪文件；会覆盖本地修改时由 Git 拒绝操作。不自动 stash、不创建合并提交、不变基，历史分叉时拒绝操作。

- 游离 HEAD、无提交分支或未配置上游时禁用 Push/Pull；请先在终端中设置上游。

- Fetch 更新所有已配置远程仓库的分支引用并清理已删除的远程引用，不切换或合并分支。刷新分支列表重新读取 Local/Remote。

- Git 操作在后台线程中串行执行；控件显示执行状态，右键菜单显示完成提示。失败会显示错误，操作后刷新文件、Git 和 GitHub 面板，部分失败也会刷新。

- 菜单支持方向键、Home/End、Enter、Escape 和外部点击关闭，打开时不触发应用快捷键。切换期间阻止重复请求和编辑器跳转，过期响应不会覆盖新分支状态。

### 二进制终端输出

终端输出通过带有小型 JSON 元数据头的二进制帧跨越桌面到 WebView 的边界。渲染端将接收缓冲区的字节视图直接交给 xterm，不再创建 JSON 数字数组或再次复制输出；消费确认仅保留元数据。

桌面端在等待确认前释放原始帧。会话标识、回放尺寸／顺序、输出背压、回滚设置和本地会话服务协议保持不变。

格式错误的帧会显示连接错误，并分离受影响的视图。Tauri 内部可能将小型二进制消息编码为 JavaScript 字节数组；大帧使用其二进制 IPC 响应路径。

### 连接与组件资源

连接资源控制：Redis 握手期间只预留槽位，不持有连接表锁，其他连接仍可读写或断开；Redis 与数据库各自的八连接上限均计入正在握手的连接，失败自动释放名额。组件下载保留分片，以便中断或取消后续传；离线导入和解压仍使用临时文件，失败或取消会回收。

- 校验使用 64
  KiB 缓冲，解压直接读取文件。组件状态通过完成事件更新，不再按秒重复读取和校验驱动；关闭的组件详情及隐藏的未连接工作台不加载组件状态。

## 数据库连接与可选组件

### 数据库配置与区域显示

工作区的“数据库”区域支持 MySQL、PostgreSQL、Oracle 服务名、Elasticsearch 和 MongoDB 连接。点击区域加号添加配置，选择后点击“连接”。SQL 数据库打开 SQL 工作台，Elasticsearch 与 MongoDB 打开文档工作台。

- 底部数据库图标独立显示／隐藏该区域，保留连接、SQL 和事务。已连接、忙碌或有草稿的配置不能编辑或移除，引用的 SSH 配置与所属工作区同样受保护。

- 从侧栏打开数据库组件时暂时隐藏项目检查器，返回项目后恢复工具与位置。

### 数据库凭据

配置保存端点、数据库／服务名、用户名、验证证书的 TLS／PEM
CA、可选系统 OpenSSH 目标及不透明凭据引用。密码默认仅在内存中保留，“记住密码”存入 macOS 钥匙串或 Windows 凭据管理器。

- 凭据绑定端点、TLS 信任和解析后的 SSH 身份，目标变化需要重新输入。凭据仅通过进程标准输入传递，不进入进程参数或诊断信息。

- 工作区 schema 7 从旧数据升级时保留备份；旧应用会拒绝读取，避免静默丢弃数据库配置。

### Java 与驱动组件

SQL 与 MongoDB 连接引擎内置于应用（35,462 字节），源码、校验值与 JAR 一起校验。连接时原子恢复缺失或被修改的带版本缓存。

- 主应用构建无需 JDK。Java 与厂商驱动仍为可选组件，不进入主安装包。

- 先验证显式选择的 Java，再从 JAVA_HOME、PATH 和平台目录检测可运行的 Java
  17+，最后回退到托管运行时。设置、侧栏及连接窗口均有组件管理入口；缺少组件不会替换 SQL 编辑器。

- “安装所需组件”显示缺失下载大小，仅安装所选依赖，不自动下载或修改系统 Java。在线／离线安装必须匹配目录中的版本、精确大小和 SHA-256，便携 Temurin
  21 使用 TUNA 镜像包。

- 解压限制路径、体积和文件数。中断／取消的下载前缀跨重启保留，继续下载使用经过验证的 HTTP
  Range，不支持时重新下载；已校验的完整包会保留供安装重试复用，每次复用仍校验目录中的大小和 SHA-256，在线运行时归档直接从保留的缓存校验并解压，离线导入和驱动替换仍使用独立临时暂存文件。

- 临时网络／服务端失败最多尝试下载三次；取消、证书、存储、文件不存在和校验失败不会循环重试。限流及服务端 Retry-After 指引会返回稍后重试提示。

- 每个组件在“离线安装”旁提供“手动下载”。完整包和分片缓存沿用更新缓存的有界清理规则。

- 卸载保留配置，数据库连接存在时禁用。

### 数据库 TLS 与 SSH

支持直连、验证证书的 TLS 和已有 OpenSSH 配置。隧道使用限制目标的回环 SOCKS 代理及一次性令牌认证，JDBC 保留原主机名用于证书校验。

- TLS 使用所选 Java 信任库或指定 PEM
  CA，不关闭主机名检查。MySQL／PostgreSQL 使用官方 JDBC 驱动，Oracle 使用 JDBC Thin 服务名。

- 暂不支持 SID、Wallet／云预设、任意 JDBC URL、自定义驱动导入或安装服务端。

### Elasticsearch 与 MongoDB 文档工作台

从“数据库”区域添加连接，选择 Elasticsearch 或 MongoDB。Elasticsearch 默认端口为 9200，可选用户名／密码或已编码的 API
Key；MongoDB 默认端口为 27017，可单独设置认证数据库，默认
`admin`。不填写凭据可连接允许匿名访问的服务。

- Elasticsearch 复用内置 HTTP 客户端，无需 Java 或驱动下载。MongoDB 通过“数据库组件”按需安装 Sync、Core 与 BSON 三个固定版本驱动，合计下载 2,779,903 字节；它们与可选 Java 运行时不进入主安装包。

- MongoDB 使用单个主机和端口，设置
  `directConnection=true`。支持独立服务或可直接访问的副本集成员，不提供 SRV、多主机发现、分片路由配置或任意连接 URI。SQL 工作台的事务、表格编辑和执行计划不适用于文档连接。

#### 浏览与查询文档

1. 连接后选择数据库及集合，或指定一个 Elasticsearch 索引。“刷新对象”最多加载 500 个名称；也可直接输入有权限访问的名称。
2. Elasticsearch 输入 Query DSL 请求体，例如
   `{"query":{"match_all":{}}}`，可查看索引 Mapping。MongoDB 输入
   `{"filter":{},"sort":{"_id":1}}`，可选 `projection`，或使用 `{"pipeline":[{"$match":{}}]}`
   执行只读聚合。
3. 点击“执行查询”或按 Ctrl/Cmd+Enter。结果每页最多 50 个文档，可翻阅前 10,000 条；分页重新查询，不保留快照。修改查询后，先从首页重新执行，再使用分页。Elasticsearch 的
   `from`、`size`、`search_after` 等分页参数由工作台管理，不能在查询中指定。

MongoDB 使用规范 Extended
JSON 保留 ObjectId、日期和数值类型；查询、编辑与导出保持 JSON 文本，不经过前端数字重新序列化。聚合的
`$out`、`$merge`
和服务器 JavaScript 操作被拒绝，包括嵌套管道中的这些操作。Elasticsearch 结果保留大整数，来源筛选后的文档不允许替换或删除。

- 查询和单个文档最多 262,144 字符；每页文档预算约 1 MiB，Elasticsearch 附加元数据与文档合计最多 2
  MiB，传输上限 8
  MiB。超限明确报错，不以截断文档继续编辑。查询服务端预算为 30 秒；“取消查询并断开”关闭连接并保留草稿。

- “保存 JSON”保存当前查询；“导出本页 JSON”仅导出已加载文档。查询与文档草稿保留在内存中，隐藏工作台仍保留连接和草稿；切换目标或文档前，未保存的文档修改需要确认放弃。退出保护同时覆盖两类草稿。

#### 文档写入与连接保护

连接默认只读。开启“允许编辑”后，可新建文档，或选择查询结果后替换／删除文档；每次写入均需确认。写入立即生效，不提供提交、回滚或自动重试。MongoDB 账号权限与 Elasticsearch 服务端权限仍然有效。

- 替换和删除使用冲突检查：Elasticsearch 发送原始序列号与主分片任期；MongoDB 按 `_id`
  和完整原始文档匹配，保留 BSON 类型。文档变化、投影缺失字段或聚合改变文档后，操作可能失败，草稿保留供核对。MongoDB 替换不得改变
  `_id`。

- TLS 验证证书和主机名，可指定 PEM CA。两者沿用经过认证且仅绑定回环地址的 SSH
  SOCKS 通道，固定转发至配置端点；MongoDB 不自动发现其他节点。密码和 API
  Key 可使用原有系统凭据库保存，绑定端点、认证方式／认证库、TLS 信任及 SSH 身份。

- 超时或连接丢失时，写入结果可能未知，需要重连并核对服务端状态后再操作。诊断返回固定错误码，不回显厂商错误中的文档或凭据。连接和正在握手的请求沿用八个数据库名额，文档连接不创建 SQL 辅助浏览进程。

协议依据：[Elasticsearch Search API](https://www.elastic.co/docs/api/doc/elasticsearch/operation/operation-search)、[MongoDB Extended JSON](https://www.mongodb.com/docs/drivers/java/sync/current/data-formats/document-data-format-extended-json/)
和 [MongoDB SOCKS5](https://www.mongodb.com/docs/drivers/java/sync/current/security/socks/)。

可隐藏／调整对象区，使用指针或聚焦后的方向键调整 SQL／结果高度。窄窗口工具栏横向滚动，分页固定底部。

### 只读进程与查询取消

连接默认只读，此时浏览复用现有进程并在读取后回滚。开启编辑后，仅在需要浏览时额外打开独立只读进程，浏览不会结束 SQL 写入事务；关闭编辑会回收辅助进程。

- 断开关闭两者。八个进程名额包含主连接、辅助浏览与正在打开的连接，可容纳八个只读工作台或四个同时使用两种进程的工作台。

- 辅助浏览故障保留 SQL 连接和事务，重试新建浏览进程。SQL 响应超时／确认丢失时关闭连接并保留草稿。

- 查询服务端超时 30 秒，响应等待上限 40 秒。“取消查询”明确关闭连接；保留连接的驱动取消继续暂缓，避免模糊写入结果。

- 不确定的写入不会自动重试。

### 表格编辑与事务

开启“允许编辑”后执行其他 SQL 需确认，提交／回滚显式处理共享事务，DDL 可能自动提交。事务指示采用保守策略，编辑模式 SELECT 也标记待处理。

- 可编辑表格要求普通表、非空主键、受支持的标量列及事务支持，MySQL 必须为 InnoDB。视图、无主键、BLOB／CLOB／厂商特殊类型列及非事务表保持只读，任意 SQL 查询结果同样只读。

- 更新不能修改主键／生成列，插入省略生成值。双击可写单元格或点击“编辑单元格”，区分 NULL 和文本，再“暂存单元格修改”；新增行与删除／恢复当前行也先生成草稿。

- 最多 100 行修改，草稿载荷 768 KiB，单值最多 16,384 字符。包含截断值的行不能编辑或删除。

### 应用草稿与故障恢复

“预览表格修改”展示带占位符的 SQL 与绑定参数。“应用到事务”按主键锁定并比较原始标量值，过期／删除的行或表元数据变化会明确失败。

- 失败只回滚本批保存点，保留草稿及此前 SQL 写入。本批执行预算 25 秒，之后进行有界刷新。

- 成功后显示当前事务数据，仍需“提交事务”；“回滚事务”恢复已提交数据。刷新、服务端筛选、导出及翻页不会覆盖未应用草稿，切换表、断开或放弃需确认。

- 意外断线保留表快照和草稿供核对，重新使用前须重连并确认服务端状态。退出／更新保护覆盖所有 SQL 与表格草稿、进行中的操作和事务，并显示需要处理的隐藏工作台。

### 导出与执行计划

CSV／JSON 通过原生保存窗口仅导出已加载页面，输出上限 8 MiB，原子保存。CSV 使用 UTF-8
BOM、字段引用、`\N`
表示 NULL，并防护电子表格公式；JSON 保留字段描述、精确数字字符串、NULL、二进制和截断标记。

- 导出不包含未应用草稿，不查询全表。“执行计划”解释选中／当前的一条只读查询，不使用 ANALYZE；MySQL 使用 EXPLAIN，PostgreSQL 使用 EXPLAIN
  (FORMAT JSON)。

- Oracle 需开启编辑且具备 PLAN_TABLE／DBMS_XPLAN 权限，通过保存点移除计划行并保留此前写入。PostgreSQL／Oracle 真实服务验收仍待完成。

### 结果与内存限制

结果限制为 256 列、每页 200 行、偏移最多 10,000、每单元格 16,384 个文本字符或 4,096 个二进制字节、序列化单元格字符预算 1,048,576、传输 8
MiB。数值保持字符串，二进制为 Base64。

- 每 JVM 堆上限 192
  MiB，驱动可能自行缓冲数据，因此结果限制不等于进程 RSS 保证。历史、草稿和结果缓存保留于内存，除非明确保存／导出。
