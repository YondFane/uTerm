工作流，不必被窗口打断

从本机到远程，
上下文始终在场。

把每天会用到的工具放在触手可及的地方。按项目组织，用熟悉的方式工作。

01 / WORKSPACE

按项目，理清工作现场。

用工作区、项目和 Git Worktree 组织终端与 Agent。分屏并排处理任务，重新连接后台会话，接着上次的思路。

WorkspacesWorktrees分屏
02 / REMOTE

远程，也在手边。

复用系统 OpenSSH 和已有连接配置。打开远程终端，用 SFTP 浏览、编辑和传输文件，无需来回寻找窗口。

SSHSFTPssh-agent
03 / DATA

查数据，留在当前思路。

浏览 Redis Key，查询 MySQL、PostgreSQL 与 Oracle。默认只读，按需开启编辑，预览修改后再明确提交。

RedisSQL默认只读
04 / CONTEXT

代码、差异，一起看。

查看文件、Git 差异和提交，预览 Markdown 与 PDF。文本编辑保留冲突检查和草稿恢复，让操作有据可循。

GitMarkdownPDF
