## 中文

- 在侧栏添加 SSH 连接，选择 OpenSSH Host 别名后打开远程终端或文件面板；支持分屏、远程文件编辑和上传下载。文件操作需使用密钥或 ssh-agent，并先确认主机指纹。
- 在侧栏添加 Redis 连接，选择直连、TLS 或 SSH 隧道后打开工作台；可扫描 Key、查看常见数据类型，并在开启编辑后修改 String、Hash 字段和 TTL。连接默认只读，密码可保存到系统凭据库。

## English

- Add an SSH connection in the sidebar and choose an OpenSSH Host alias to open remote terminals or files, with splits, file editing, uploads and downloads. File operations require a key or ssh-agent and a trusted host fingerprint.
- Add a Redis connection in the sidebar, choose direct TCP, TLS or an SSH tunnel, then open the workbench to scan keys and browse common data types. Enable editing to modify Strings, Hash fields and TTLs. Connections start read-only, and passwords can be saved in the system credential store.
