## 中文

- 新增 MySQL、PostgreSQL 和 Oracle 工作台。在侧栏添加数据库连接，选择 Java 17+ 并按需安装驱动，即可浏览表、执行 SQL 和处理事务；Oracle 使用服务名连接。
- SSH 连接可设置主机、端口和用户名，支持密钥或密码认证；密码可保存到系统凭据库，远程文件和 Redis 隧道复用这些配置。
- Redis 二进制值新增可读文本及 Java 类描述预览，在值详情中直接查看。
- 侧栏底部可独立显示或隐藏各连接区域；改善断连提示、SQL 草稿保护和结果预览的资源占用。

## English

- Added MySQL, PostgreSQL and Oracle workbenches. Add a database connection in the sidebar, select Java 17+ and install its driver to browse tables, run SQL and manage transactions; Oracle uses service-name connections.
- SSH profiles now accept host, port and username with key or password authentication. Passwords can be saved in the system credential store, and remote files and Redis tunnels reuse these settings.
- Redis binary values now show readable text and Java class descriptors directly in value details.
- Footer buttons independently show or hide connection sections, with clearer disconnect notices, safer SQL drafts and lower resource use for result previews.
