# uTerm 0.1.47

## 中文

- Git 面板新增分支树，可搜索、收藏本地与远程分支，并浏览标签。单击预览提交历史，右键切换、创建或重命名分支。
- 本地分支右键菜单支持上游设置、仅快进更新和推送。首次推送时选择远程仓库与目标分支名称，即可建立跟踪关系。
- 右键分支或标签选择“新建 Worktree”，填写新分支名称和目录。创建后加入项目树，保留当前项目与会话选择。
- 右键分支或标签选择“与工作目录比较”，查看暂存、未暂存和未跟踪文件。点击变更文件默认在中栏展示差异，工具面板保留文件列表。
- 中栏标签改为 28 px 紧凑高度，空间不足时最多显示两行；超出部分可上下滚动，当前标签自动保持可见。

## English

- The Git panel adds a branch tree for searching and favoriting local/remote branches and browsing
  tags. Click to preview commit history; right-click to switch, create or rename a branch.
- Local branch menus support upstream settings, fast-forward-only updates and pushing. For a first
  push, choose the remote and target branch name to establish tracking.
- Right-click a branch or tag and choose New worktree, then enter its new branch name and directory.
  It joins the project tree while retaining the current project and session selection.
- Right-click a branch or tag and choose Compare with working directory to inspect staged, unstaged
  and untracked files. Clicking a changed file opens its diff in the central workspace while
  retaining the inspector's file list.
- Central tabs use a compact 28 px height and wrap to at most two visible rows. Scroll vertically
  for additional tabs; the active tab stays visible automatically.
