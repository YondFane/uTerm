## 中文

- 修复“设置 → 用量”读取大日志或尚未写完整的日志时出现 UTF-8 错误的问题。Claude、Codex、Kimi 和 Grok 的有效记录可继续统计，未能读取的部分会显示提示。
- 修复 Windows 一键安装在续传或复用缓存后无法启动安装向导的问题。重新执行官网或 README 中的安装命令即可使用。

## English

- Fix UTF-8 errors in Settings → Usage when reading large logs or logs still being written. Valid Claude, Codex, Kimi and Grok records continue to count, with a notice for unreadable portions.
- Fix the Windows one-line installer failing to launch its wizard after resuming or reusing a cached download. Run the installation command from the website or README again to use it.
