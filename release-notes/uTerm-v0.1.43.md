# uTerm 0.1.43

## 中文

- 文件列表支持删除本地和远程目录及其全部子目录和文件。右键选择“删除”，核对路径后确认；此操作无法撤销，所选根目录仍受保护。
- Elasticsearch 连接可直接粘贴 HTTP/HTTPS 根地址，自动填入主机、端口和 TLS 设置，并为无效地址和端口显示具体提示。在“添加数据库连接”中选择 Elasticsearch 后填写地址，再测试或保存连接。

## English

- Delete local and remote directories with all their subdirectories and files from the file list.
  Right-click, choose Delete and confirm the path; deletion cannot be undone, and the selected root
  remains protected.
- Paste an HTTP/HTTPS root URL into an Elasticsearch connection to fill its host, port and TLS
  settings, with specific errors for invalid addresses and ports. Select Elasticsearch under Add
  database connection, enter the address, then test or save the connection.
