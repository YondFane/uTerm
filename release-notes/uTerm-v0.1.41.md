# uTerm 0.1.41

## 中文

- 调整 macOS 顶部栏：原生红黄绿窗口按钮与工作区名称、工具按钮对齐。将指针停在绿色按钮上，可使用系统窗口排列和全屏菜单。
- 侧栏收起或变窄时，顶部控件为窗口按钮预留空间，减少遮挡；左侧工具面板同样适用。

## English

- Align the native macOS window buttons with the workspace name and toolbar buttons. Hover over the
  green button to use the system window arrangement and full-screen menu.
- Reserve space for window buttons when the sidebar collapses or narrows, reducing overlap with
  toolbar controls. This also applies to a left-side tool panel.
