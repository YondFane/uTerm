## 中文

- 鼠标中键点击左侧栏会话条目或终端窗格标题，即可关闭对应终端或 Agent 会话。
- 右键点击应用界面不再出现“打印”“另存为”“更多工具”等浏览器默认菜单，项目、会话、文件和分支的应用菜单仍可使用。
- 更新安装前显示十秒确认倒计时，可点击“立即安装”，或点击“取消”／按 Escape 停止本次安装；不操作则倒计时结束后安装并重启。取消后可在“设置 → 软件更新”中手动安装。

## English

- Middle-click a session row in the sidebar or a terminal pane title to close the corresponding terminal or Agent session.
- Right-clicking the application no longer shows browser menus such as Print, Save as or More tools. Application menus for projects, sessions, files and branches remain available.
- A ten-second confirmation countdown appears before installing an update. Choose Install now, or choose Cancel / press Escape to stop this installation; without a response, the update installs and restarts the app when the countdown ends. After cancelling, install manually in Settings → Software update.
