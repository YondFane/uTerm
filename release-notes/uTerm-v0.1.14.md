## 中文

- 在 Git → 变更中，右键点击“已暂存”或“工作目录”的文件，选择“回滚文件”并确认，将该文件的暂存和工作目录改动恢复到 HEAD。新增文件会被删除，确认前请检查路径，此操作无法撤销。
- 回滚前会先保存打开的文件；保存冲突时保留草稿并等待处理。回滚完成后自动刷新文件和变更列表。

## English

- In Git → Changes, right-click a file in Staged or Working directory, choose Roll back file and confirm to restore its staged and working changes to HEAD. Added files are deleted; check the path before confirming, as this cannot be undone.
- Open files are saved before rollback; save conflicts preserve the draft and wait for resolution. File and change lists refresh automatically after rollback.
