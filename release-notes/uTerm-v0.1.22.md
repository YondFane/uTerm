## 中文

- 左键点击侧栏项目或 Worktree 行即可展开、折叠子项，文件夹图标悬停时不再切换为下拉箭头。
- 右键点击 SSH 连接可新建终端或编辑配置；右键点击 Redis、数据库连接可编辑配置。聚焦连接行后也可按 Shift+F10 打开菜单。
- 移除 SSH、Redis 或数据库连接时，先核对确认窗口中的连接名称，再点击“确认移除”；取消或按 Esc 会保留配置和已记住的密码。
- 侧栏的关闭会话和移除连接按钮在鼠标悬停或键盘聚焦时显示，让连接与会话列表更简洁。
- 使用状态仅将外围圆环和光晕显示为绿色，项目、SSH、Redis 和数据库图标保留原色。

## English

- Left-click a sidebar project or Worktree row to expand or collapse its children. Hovering its folder icon no longer replaces it with a dropdown arrow.
- Right-click an SSH connection to create a terminal or edit its profile; right-click a Redis or database connection to edit its profile. Press Shift+F10 on a focused connection row to open the same menu.
- Removing an SSH, Redis or database connection shows its name for confirmation. Click Confirm removal to proceed; Cancel or Esc keeps the profile and its remembered password.
- Sidebar Close Session and Remove connection buttons appear on hover or keyboard focus, keeping connection and session lists compact.
- Active resources show a green outer ring and glow while project, SSH, Redis and database icons retain their original colors.
