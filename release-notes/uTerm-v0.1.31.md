## 中文

- 加粗公共文字及侧栏、工具栏图标，并提高深浅主题文字对比度，让设置、分区标题和分支名称更清晰。
- macOS 新增“会话”和“工作区”菜单：切换上一个／下一个会话，按分组选择指定会话，以及切换或新建工作区。
- 在 macOS“视图”菜单中切换侧栏、工具面板及 Git 等面板。通过“uTerm
  → 设置”切换语言或自定义快捷键，菜单同步更新。

## English

- Strengthen shared text, sidebar icons and toolbar icons, with higher text contrast in dark and
  light themes for clearer settings, section headings and branch names.
- Use the new macOS Session and Workspace menus to move between sessions, select a session by group,
  and switch or create workspaces.
- Toggle the sidebar, inspector and panels such as Git from the macOS View menu. Change language or
  customize shortcuts in uTerm → Settings; the menus update immediately.
