## 中文

- 无需安装 Hooks 即可接收任务提醒。在“设置 →
  Agent”开启“任务完成或需要处理时通知”，再新建会话。Codex、OpenCode 可提供精确状态；其他原生终端通知或响铃显示为通用提醒，并进入托盘任务列表。部分 CLI 需先开启自身通知，Codex 使用本次启动专用配置时保留通用提醒。

- 在终端和文件标题栏使用 A−／A+ 调整字号，或用 Ctrl+-／Ctrl++ 调整当前内容；macOS 使用 Command。终端、文件与 Git 差异字号分别保存，连续调整保持每次增量。

- 右键点击文件标签或“快速打开”的文件结果，可复制文件、名称、完整路径，或在文件管理器中定位；操作保留当前文件和草稿。

- 在“Git → 历史”点击提交，查看完整提交信息、作者、时间、哈希及变动文件，再选择文件查看差异。

- 右键点击托盘图标，通过“开启自启动”切换登录启动，并同步通用设置中的开关。

- 拖动侧栏、工具面板及分屏分隔条后，终端在尺寸稳定时统一适配，减少连续重排。

## English

- Receive task reminders without installing hooks. Enable Notify when tasks finish or need attention
  in Settings → Agent, then start a new session. Codex and OpenCode can provide precise states;
  other native terminal notifications or bells appear as general reminders and enter the tray task
  list. Some CLIs require their own notifications to be enabled first; Codex with
  invocation-specific configuration retains general reminders.

- Use A−/A+ in terminal and file headers, or Ctrl+-/Ctrl++ for the current content; use Command on
  macOS. Terminal, file and Git diff sizes save independently, and rapid adjustments retain every
  increment.

- Right-click a file tab or a Quick open file result to copy the file, name or full path, or reveal
  it in File Manager. Actions retain the current file and draft.

- Click a commit in Git → History to inspect its full message, author, time, hash and changed files,
  then select a file to view its diff.

- Right-click the tray icon and use Launch at login to change startup behavior and synchronize the
  General settings switch.

- After dragging sidebar, inspector or split dividers, the terminal fits once dimensions settle to
  reduce repeated reflow.
