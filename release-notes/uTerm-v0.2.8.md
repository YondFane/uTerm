# uTerm 0.2.8

## 中文

- macOS 原生个人版支持自动更新：在**设置 → 通用**开启**自动检查并下载更新**并保存，下载完成的更新可在退出应用时安装。0.2.6 用户需先手动安装本版一次。
- 更新状态随中英文界面语言切换，检查结果和下载提示使用当前语言。

## English

- Enable automatic updates in the native personal macOS app: turn on **Automatically check and
  download updates** in **Settings → General** and save. Downloaded updates can install on quit;
  users of 0.2.6 must first install this version manually once.
- Update status follows the interface language, displaying check results and download messages in
  the selected language.
