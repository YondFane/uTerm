## 中文

- 侧栏标题统一为 SSH、Redis、数据库，并与“项目”对齐。点击标题可独立折叠或展开，保留会话、连接和草稿。
- 数据库组件自动检测并优先使用本机 Java 17+；未检测到时可选择本机 Java，或通过镜像下载安装运行时。
- 组件下载中断或取消后保留进度，在组件页面点击“继续下载”即可重试。
- 仓库 Latest 入口在发布完成后指向最新稳定版。

## English

- Sidebar headings are now SSH, Redis and Databases, aligned with Projects. Click a heading to fold or expand its section while retaining sessions, connections and drafts.
- Database components automatically detect and prefer local Java 17+. If none is found, choose local Java or download and install the runtime from the mirror.
- Interrupted or cancelled component downloads retain progress. Click Resume download on the components page to retry.
- The repository’s Latest entry points to the newest stable version after publication completes.
