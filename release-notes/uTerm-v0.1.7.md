## 中文

- **用量查询与详情**：设置中的 Agent 与用量已拆分为独立页面；打开“用量”会自动查询 Claude，切换标签即可查询 Codex、Kimi 或 Grok。可设置 10–3600 秒的剩余用量刷新间隔；点击工作区标题栏的剩余百分比可查看各额度窗口、进度和重置时间。
- **窗格按钮位置**：交换左右窗格后，工具面板显示／隐藏按钮会移动到主工作区标题栏靠近分隔线的一侧，不再占用文件或 Git 工具栏。
- **设置与更新状态**：全局“恢复界面与终端默认设置”入口统一放在设置 → 通用。更新下载期间和完成后，已下载大小紧邻进度条显示，便于确认进度。

## English

- **Usage queries and details**: Agents and Usage are now separate Settings pages. Opening Usage queries Claude automatically; switch tabs to query Codex, Kimi, or Grok. Set the remaining-usage refresh interval from 10–3600 seconds, and click the remaining percentage in the workspace title bar to view quota windows, progress, and reset times.
- **Pane button placement**: After swapping the left and right panes, the inspector show/hide button moves to the side of the main workspace title bar nearest the divider instead of occupying the Files or Git toolbar.
- **Settings and update status**: The global “Restore interface and terminal defaults” action now appears only in Settings → General. During and after an update download, the downloaded size stays beside the progress bar for clearer status.
