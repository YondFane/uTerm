# uTerm 0.1.46

## 中文

- Git 变更文件右键菜单新增“打开文件”，可直接编辑当前文件；单击文件仍查看差异，原有“回滚文件”操作保留。
- 统一使用图标导航侧栏，移除经典布局与侧栏样式选择。通过左侧图标切换连接和项目区域；界面主题仍可在“设置 → 外观”中调整。

## English

- Add Open file to the Git changed-file context menu to edit the current file directly. Clicking a
  file still shows its diff, and Roll back file remains available.
- Use the icon navigation sidebar throughout and remove the classic layout and sidebar style picker.
  Switch connection and project sections using the left-hand icons; adjust the interface theme in
  Settings → Appearance.
