# uTerm 0.1.38

## 中文

- 改善滚动后拖选终端文字时的界面响应，并减少后台会话持续输出带来的渲染开销。
- 新增 TRAE CLI 支持。在“设置 → Agent → TRAE
  CLI”中安装并启用，然后新建项目或独立聊天；首次使用需在 CLI 中完成登录和初始化。

## English

- Improve interface responsiveness when selecting scrolled terminal text and reduce rendering
  overhead from background session output.
- Add TRAE CLI support. Install and enable it in Settings → Agent → TRAE CLI, then start a project
  or standalone chat. Complete sign-in and initial setup inside the CLI before first use.
