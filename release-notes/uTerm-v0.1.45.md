# uTerm 0.1.45

## 中文

- 优化多项目、多会话工作区中的侧栏、会话切换与分屏调整性能。打开已有工作区并照常使用即可，无需更改设置。

## English

- Improve sidebar, session-switching and split-resizing performance in workspaces with many projects
  and sessions. Open an existing workspace and use these controls as usual; no settings changes are
  needed.
