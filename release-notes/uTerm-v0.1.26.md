## 中文

- 项目与 Worktree 行不再显示省略号按钮，保留新建终端和 Agent 快捷入口；右键点击行可打开项目操作。
- 文件列表右键菜单按窗口空间展开，便于访问“在文件管理器中打开”等操作。
- OpenCode、Kimi 和 Grok 在 Agent 设置、侧栏及会话标签中使用各自的品牌图标。
- 终端和 Agent 会话支持慢转滚轮时小步滚动、连续快转时加速；停顿或反向后恢复小步，便于精确查看历史内容。
- 修复 Windows Agent Hooks 状态上报和重复安装问题，并保留其他工具及自定义命令。在“设置 → Agent”重新安装 Hooks 后，新建 Agent 会话即可使用。
- 开启“设置 → Agent → 任务完成或需要处理时通知”后，后台任务可发送通知；关闭通知、查看或关闭会话、任务状态更新后，不再发送过期通知。

## English

- Project and Worktree rows keep their terminal and Agent shortcuts without an ellipsis button. Right-click a row to open project actions.
- File-list context menus fit the available window space, keeping actions such as Open in File Manager accessible.
- OpenCode, Kimi and Grok use their brand icons in Agent settings, the sidebar and session tabs.
- Terminal and Agent sessions scroll in small steps when the wheel turns slowly and accelerate during faster consecutive turns. Pausing or reversing restores small steps for precise history navigation.
- Fix Windows Agent Hook reporting and duplicate installation while preserving other tools and custom commands. Reinstall Hooks in Settings → Agent, then start a new Agent session.
- Enable Settings → Agent → Notify when tasks finish or need attention for background task notifications. Pending notifications are discarded after opting out, viewing or closing the session, or receiving a newer task state.
