# uTerm 0.1.40

## 中文

- 优化 Agent 管理界面：在“设置 →
  Agent”中按名称、标识或程序搜索，筛选可用或已启用的 Agent；选择条目后查看安装、配置和 Hooks 操作。宽面板左右排列，窄面板自动改为上下排列。

## English

- Browse Agents in a compact list in Settings → Agent. Search by name, ID or program, filter by
  availability or enabled status, then select an Agent for installation, configuration and Hooks
  actions. Wide panels show details alongside the list; narrow panels stack them below.
