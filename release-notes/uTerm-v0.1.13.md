## 中文

- 在“设置 → 外观”中分别调整“文件查看字号”和“Git 对比字号”（10–32 px）。更改立即生效并自动保存，保留当前编辑内容、选区与撤销记录。
- 开机自启动现在只驻留系统托盘，不自动打开主界面；点击托盘图标即可打开。已有自启动项请在“设置 → 通用”中关闭再开启“开机自启动”。
- Git 面板恢复焦点时减少重复刷新，并继续更新内容已改变的差异；同时减少文件列表、项目搜索和终端回放的处理开销。

## English

- In Settings → Appearance, adjust File font size and Git diff font size independently (10–32 px). Changes apply immediately and save automatically while preserving edits, selection and undo history.
- Launch at login now keeps uTerm in the system tray without opening the main window; click the tray icon to open it. For an existing startup entry, turn Launch at login off and on in Settings → General.
- The Git panel avoids duplicate refreshes when focus returns while keeping changed diff contents current. File listing, project search and terminal replay also perform less processing.
