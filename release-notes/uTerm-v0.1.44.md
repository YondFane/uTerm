# uTerm 0.1.44

## 中文

- 删除目录时改用居中弹窗确认，显示完整路径和递归删除提示，默认聚焦“取消”。在文件列表中右键目录并选择“删除”，核对后确认；点击“取消”或按 Esc 可返回目录。
- 图标导航侧栏成为默认样式，设置 → 外观中的预览卡片移到左侧。已保存的样式选择会保留；需要切换时选择该卡片，或使用“恢复界面与终端默认设置”。

## English

- Confirm directory deletion in a centered dialog showing the full path and recursive deletion
  warning, with Cancel initially focused. Right-click a directory in the file list and choose
  Delete, then review and confirm; Cancel or Escape returns to the directory.
- The icon navigation sidebar is now the default, with its preview card on the left under Settings →
  Appearance. Saved style choices are retained; select the card or use Reset interface and terminal
  settings to switch.
