# uTerm 0.2.10

## 中文

- macOS 原生个人版新增**设置 →
  Java 开发环境**。可检测本机 JDK，手动添加或移除 JDK 记录；移除记录保留原有文件。
- 在同一页面按需安装 JDK
  8／11／17／21 或 Maven，也可手动下载后离线导入。安装显示进度并支持取消，打开页面不会自动下载工具。

## English

- The native personal macOS app adds **Settings → Java development tools**. Detect local JDKs or add
  and remove JDK records manually; removing a record preserves its files.
- Install JDK 8, 11, 17, 21 or Maven as needed on the same page, or download an archive manually and
  import it offline. Installation shows progress and supports cancellation; opening the page does
  not download tools.
