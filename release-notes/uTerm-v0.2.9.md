# uTerm 0.2.9

## 中文

- macOS 原生个人版补充顶栏快捷入口、工作区管理和项目筛选；可在侧栏右键置顶、折叠或调整项目顺序。
- 在**设置**左侧切换分类，使用字体预设、全局 Maven 设置及数据库组件管理；已有自定义字体和未保存草稿会保留。
- 会话右键菜单支持置顶、排序、组合和取消组合，操作时保留正在运行的终端。
- 后台读取数据库组件目录时，保存连接配置不再被误判为操作冲突。

## English

- The native personal macOS app adds toolbar shortcuts, workspace management and project filters.
  Use a project's sidebar menu to pin, collapse or reorder it.
- Navigate settings from the left to choose font presets, edit global Maven settings or manage
  database components. Existing custom fonts and unsaved drafts are retained.
- Session menus support pinning, ordering, grouping and ungrouping while retaining running
  terminals.
- Saving a database connection no longer reports a conflicting operation solely because its
  component catalog is being read in the background.
