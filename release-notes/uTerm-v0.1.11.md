## 中文

- 中栏支持鼠标中键关闭文件和 Git 差异标签。关闭文件仍会先保存修改并保留冲突保护；终端和会话继续通过左侧栏关闭。

- 没有打开文件或 Git 差异时隐藏中栏标签栏，终端和会话仍可从左侧栏切换。

## English

- Middle-click file and Git diff tabs in the main workspace to close them. File closing still saves edits and preserves conflict protection; close terminals and sessions from the sidebar.

- Hide the main tab bar when no files or Git diffs are open; switch terminals and sessions from the sidebar.
