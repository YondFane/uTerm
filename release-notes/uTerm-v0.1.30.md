## 中文

- 在“设置 → 外观 → 侧栏样式”选择图标导航侧栏后，SSH、Redis 和数据库入口及添加操作始终可用。切回经典侧栏时保留原有显示开关。
- 修复任务通知因权限误判无法开启或发送的问题。在“设置 → Agent”启用“任务完成或需要处理时通知”。

## English

- Choose Icon navigation sidebar in Settings → Appearance → Sidebar style to keep SSH, Redis and
  database categories and Add actions available. Switching back to Classic sidebar preserves its
  saved visibility choices.
- Fix task notifications being blocked from enabling or sending by an incorrect permission check.
  Enable Notify when tasks finish or need attention in Settings → Agent.
