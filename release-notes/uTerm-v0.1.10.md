## 中文

- 修复普通终端启动 Claude/Codex 后未显示对应 Agent 图标的问题，以及文件标签无法切换的问题。
- 在“设置 → 通用”设置文件标签数量上限，默认 10、最小 1。超限自动关闭最早打开的文件标签，保留终端和会话。
- 在“设置 → 软件更新”开启“自动更新”，可自动下载、安装并重启；未保存文件会阻止安装。
- 软件更新的进度和操作按钮位于版本说明上方；版本说明支持标题、列表排版和独立滚动。

## English

- Fix Agent icons when launching Claude/Codex from an ordinary terminal, and fix file-tab switching.
- Set the file tab limit in Settings → General (default 10, minimum 1). Excess tabs close in opening order, keeping terminals and sessions.
- Enable Automatic updates in Settings → Software update to download, install and restart automatically; unsaved files prevent installation.
- Update progress and action buttons appear above release notes, which support formatted headings, lists and independent scrolling.
