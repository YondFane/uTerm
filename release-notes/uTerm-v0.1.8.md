## 中文

- 新增一行安装：在 macOS 或 Windows 终端运行 `npx @yondfane/uterm-install` 或 `pnpm dlx @yondfane/uterm-install`，安装稳定版 uTerm；需要 Node.js 22.13 或以上及 GitHub 网络访问。
- README 提供不依赖 Node.js 的 Shell／PowerShell 安装命令。macOS 自动识别芯片并安装到 `~/Applications/uTerm.app`，完成后从访达打开；Windows 打开安装向导。macOS 已有安装时请使用应用内更新。

## English

- Install stable uTerm from a macOS or Windows terminal with `npx @yondfane/uterm-install` or `pnpm dlx @yondfane/uterm-install`. Node.js 22.13 or newer and GitHub access are required.
- The README also provides Shell/PowerShell installation commands without Node.js. macOS detects the chip and installs to `~/Applications/uTerm.app`; open it from Finder when finished. Windows opens the installation wizard. For an existing macOS installation, use in-app updates.
