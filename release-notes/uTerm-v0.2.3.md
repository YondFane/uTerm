# uTerm 0.2.3

## 中文

- 修复 Java／Python 运行日志中“自动跟随”复选框与文字分离的问题。点击文字或使用空格键即可切换跟随，向上滚动仍会暂停跟随。
- Python 运行面板中的“保存配置”改为紧凑按钮，位于高级设置字段下方右侧，展开高级设置后即可使用。
- 官网和 README 重新整理功能介绍、界面预览及下载入口，便于了解项目并选择对应平台的安装包。

## English

- Fix the separated Auto follow checkbox and label in Java/Python run logs. Click the label or use
  Space to toggle following; scrolling up still pauses it.
- Python run now uses a compact Save configuration button below the advanced fields on the right.
  Expand Advanced settings to access it.
- The website and README reorganize feature descriptions, interface previews and download links,
  making it easier to explore the project and choose an installer for your platform.
