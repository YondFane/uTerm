# uTerm 0.1.36

## 中文

- 优化终端和 Agent 会话中拖动选择文字时的流畅度，减少密集输出中的卡顿。
- 新增上一个／下一个工作区快捷键：Windows 使用 Ctrl+Alt+[／]，macOS 使用 Cmd+Option+[／]，可循环切换并恢复各工作区的选择；在“设置 → 快捷键”中可自定义。
- 修复打开设置和 Agent 窗口时关闭按钮出现额外焦点框的问题，保留 Tab 键导航的焦点提示。

## English

- Improve text-selection responsiveness in terminal and Agent sessions, reducing stalls in dense
  output.
- Switch to the previous or next workspace with Ctrl+Alt+[ / ] on Windows or Cmd+Option+[ / ] on
  macOS. Navigation wraps around and restores each workspace's selection; customize the bindings in
  Settings → Shortcuts.
- Remove the extra close-button focus outline when Settings and Agent dialogs open, while retaining
  focus indicators for Tab navigation.
