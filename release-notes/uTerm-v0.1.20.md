## 中文

- Redis 工作台采用紧凑布局。在侧栏打开 Redis 连接后，可拖动或用方向键调整 Key 导航宽度；窄窗口通过“浏览 Key”抽屉搜索和选择数据。
- 点击 Hash 字段，在保留成员列表和匹配规则的同时编辑字段值。切换或关闭编辑区时可保存、放弃或取消，刷新 Key 列表也会保留草稿。
- 开启“允许编辑”后，从导航栏新建 Key，从详情顶部设置 TTL，从更多菜单重命名或删除。界面明确显示字节数、成员数、过期时长及扫描状态。

## English

- The Redis workbench uses a compact layout. Open a Redis connection from the sidebar, then drag or use arrow keys to resize key navigation; narrow windows use the Browse keys drawer to search and select data.
- Click a Hash field to edit its value while retaining the member list and pattern. Switching or closing the editor offers Save, Discard or Cancel, and refreshing the key list retains drafts.
- Enable editing to create a key from navigation, set TTL from the detail header, or rename and delete through the actions menu. The interface clearly shows byte lengths, member counts, expiration durations and scan status.
