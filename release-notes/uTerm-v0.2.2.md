# uTerm 0.2.2

## 中文

- Java／Python 面板随项目和 Worktree 选择切换，展示对应配置、任务与日志。切换前保存原配置；当前操作未完成或保存失败时，保留草稿并恢复原项目。
- 右击顶部 Java 或 Python 图标可查看对应的启动列表。选择运行项即可打开其项目和日志，支持跨工作区及 Worktree 定位。
- 启动 Java／Python 项目后，侧栏对应项目或 Worktree 显示绿色 Java／蓝黄 Python 图标，已固定项目也适用；任务结束后恢复文件夹图标。
- 修复其他界面主题下日志文字不清晰的问题。日志文字与背景统一使用终端配色，可在“设置 → 外观”中实时切换。

## English

- Java/Python panels follow project and Worktree selection, showing the matching configuration,
  tasks and logs. The previous configuration is saved before switching; unfinished operations or
  failed saves retain the draft and restore the previous project.
- Right-click the top Java or Python icon to view its running-project list. Select an entry to open
  its project and logs, including projects in other workspaces and Worktrees.
- Running Java/Python projects show green Java or blue/yellow Python icons in their sidebar project
  or Worktree rows, including pinned projects. Folder icons return when tasks exit.
- Fix unreadable log text with other interface themes. Log text and background use the same terminal
  palette, which can be changed live under Settings → Appearance.
