## 中文

- 工具栏与侧栏采用圆润的图标分组，独立按钮悬停时显示圆框；文件列表按钮更紧凑，底部添加按钮使用无圆框的粗体加号。关闭图标统一为灰色圆形，悬停变红，macOS 保留系统原生窗口按钮。
- 项目、Worktree 和 SSH 图标在有未关闭会话时显示绿色光圈；Redis 与数据库连接成功后也会亮起。点击侧栏工作区名称可打开紧凑的切换菜单。
- 终端与 Agent 面板按滚轮距离滚动，细微触控板移动可连续累积，Alt/Option 可加快滚动。
- 在“工作目录”面板点击“在 GitLab 上查看”可打开远程仓库，支持主机名包含 gitlab 的自托管实例和嵌套分组。
- 数据库表头不再透出下方内容，结果表格显示滚动条，对象操作菜单保持在窗口内。Redis 的“重新连接”和“断开”直接显示在顶部。

## English

- Toolbars and the sidebar use rounded icon groups, with circular frames appearing on hover for standalone buttons. File-list controls are smaller, and the footer Add button uses an unframed bold plus. Close icons share gray circles that turn red on hover, and macOS retains native window controls.
- Project, Worktree and SSH icons show a green ring while they have unclosed sessions; Redis and database icons light up after connecting successfully. Click the workspace name in the sidebar to open a compact switcher menu.
- Terminal and Agent panes scroll according to wheel distance, accumulate fine trackpad movement, and support faster scrolling with Alt/Option.
- Click View on GitLab in the Working directory panel to open the remote repository, including nested groups and self-hosted instances whose hostname contains gitlab.
- Database headers no longer show content through them, result grids display scrollbars, and object-action menus stay within the window. Redis shows Reconnect and Disconnect directly in its header.
