# uTerm 0.2.11

## 中文

- macOS 原生个人版优化顶栏、分类侧栏和窄窗口布局，并统一内置终端字体。在终端面板使用搜索和字号控件；本地进程退出后可重新启动原会话。
- 文件面板在主工作区打开编辑标签，切换标签保留未保存内容，并支持跨项目／工作区复制粘贴。修复删除展开目录时的刷新错误及原生 Git 状态显示。
- 快速 SSH 和 GitHub 的**新建 PR**表单在主工作区打开；取消后保留终端和工具面板，PR 表单支持关闭后恢复草稿。
- PDF 高亮支持保存、删除和重新打开后恢复。在 PDF 工具栏开启高亮后拖动标记区域，使用**删除高亮**移除标记。
- 超长终端粘贴提示在三秒后自动消失，重复触发会重新计时，真实连接及写入错误仍保留。

## English

- The native personal macOS app improves its toolbar, category sidebar and narrow-window layout, and
  shares the bundled terminal font. Use search and font controls in each terminal pane; restart the
  same session after its local process exits.
- Files open as editor tabs in the main workspace, retain unsaved input when switching tabs and
  support copying across projects and workspaces. Fix refresh errors after deleting expanded folders
  and native Git status display.
- Quick SSH and GitHub's **New PR** form open over the main workspace. Cancel retains the terminal
  and tools; closing and reopening the PR form restores its draft.
- PDF highlights can be saved, deleted and restored when reopening a document. Enable highlighting
  in the PDF toolbar, drag over an area and use **Delete highlight** to remove a mark.
- Oversized terminal paste notices disappear after three seconds and restart their timer when
  repeated. Actual connection and write errors remain visible.
